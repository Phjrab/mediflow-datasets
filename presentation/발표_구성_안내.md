## 지표의 의미

- **Accuracy:** 평가 사진 중 맞힌 비율. 다수 클래스가 강하면 높아질 수 있다.
- **Macro F1:** 클래스별 Precision·Recall의 균형인 F1을 클래스마다 계산해 단순 평균한다. 비슷한 질환을 고르게 맞히는지 볼 때 Accuracy와 함께 본다.
- **Validation:** 설정과 체크포인트 선택에 쓴 사진. 같은 분할을 반복 사용하므로 최종 일반화 보증이 아니다.
- **Test:** 선택이 끝난 뒤 고정된 사진으로 확인한 결과. 서로 다른 클래스 구성·Test 구성 사이의 점수를 같은 척도로 빼지 않는다.
- **p50/p95:** 반복 추론 시간의 중간값과 느린 쪽 95백분위. 본 자료에서는 모델 로드·카메라·전체 앱 시간을 제외한 Colab의 지정 범위다.
- **학습 시간:** 과거 한 모델을 학습하는 데 든 시간. 다른 Colab 실행 기록은 GPU나 환경이 같다고 확인되지 않으므로 이를 동일 조건 속도 순위로 해석하지 않는다.

그림을 PPT에 삽입할 때는 그림 제목 아래 `공개 데이터 Validation` / `공개 데이터 Test` / `Colab 합성 이미지 실행 시간` 중 해당 표기를 붙이면 결과의 의미가 흐려지지 않는다. 1~4차 문서의 표에서는 화면 가독성을 위해 소수 자릿수를 줄여 썼다. **재현·인용에는 각 차수 CSV 또는 원본 JSON의 전체 수치를 사용한다.**
