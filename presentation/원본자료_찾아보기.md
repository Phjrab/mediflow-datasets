# 원본 코드·노트북·보고서 찾아보기

이 발표 폴더를 만들 때 로컬 `docs/` 60개 파일, `notebooks/` 20개 `.ipynb`, `scripts/` 26개 Python 파일, `results/` 598개 파일의 **목록을 확인**하고 각 시기의 원본 보고서·선정 모델·그림·전처리 코드를 연결했다. `.keras`·ZIP·이미지 같은 바이너리 전체를 텍스트 문서처럼 읽어 내용을 해석한 것은 아니다. 발표 폴더는 관련 근거를 쉽게 찾는 **선별본**이며 원본 저장소 전체를 복제하지 않는다.
