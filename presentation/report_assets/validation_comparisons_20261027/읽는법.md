# Validation 비교 그림 사용 안내

초안에 있는 파랑 Accuracy·주황 Macro F1 막대그래프 형식으로 네 그림을 만들었습니다.

- 01 Hair v1: 정제 후 기본 학습법 여섯 조건. 당시 Validation Macro F1은 미저장이라 Accuracy만 표시.
- 02 Web Skin v1: 기본 학습법 여섯 조건. +5회 행은 부모 최고 유지 결과.
- 03 Hair v2: 기준선·SupCon·DINOv2·EfficientNetV2-S·B1 384 Adam·SAM·MedSigLIP.
- 04 Web Skin v2: 기존 v1·WS-DAN·PMG B0·MixStyle·PMG B1·MedSigLIP.

그림은 모두 3200×1800, 200 dpi입니다. 막대 위 표시는 사용자가 요청한 소수점 4자리이며 CSV에는 원본 정밀도를 보존했습니다. 파란색은 Validation Accuracy, 주황색은 Validation Macro F1입니다. 검정 테두리와 선정 표시는 해당 버전에서 남긴 후보를 뜻합니다. 최고 값인 모든 모델을 뜻하지는 않습니다. 특히 Web Skin v2는 비용을 함께 고려한 PMG B0 256이며 PMG B1 384가 Validation 선두입니다.

정제 전 초기 결과와 정제 후 결과는 섞지 않았습니다. Hair v1은 당시 학습 기록의 선정 Validation Accuracy이고 v2는 저장 체크포인트 재평가 값입니다. 비교 설계가 다른 후보의 차이를 특정 한 요소의 인과 효과로 단정하지 않습니다. Hair5와 Web Skin을 같은 순위로 비교하지 않습니다. Test 값은 사용하지 않았습니다.
