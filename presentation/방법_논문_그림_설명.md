# 2·3차 방법 설명 그림 읽는 법

이 문서는 발표 그림에 들어간 **논문의 아이디어**, **MediFlow에서 실제로 시험한 설정**, **관찰한 결과**를 구분한다. 그림은 원리를 쉽게 설명하기 위한 도식이며 논문 속 네트워크 전체를 그대로 재현했다는 뜻이 아니다. 수치를 인용할 때는 [2차 실험표](2차/최적화_실험표.csv), [3차 실험표](3차/논문_실험표.csv)와 원본 `results/` JSON을 사용한다.

## 2차 그림

- [전이학습 구조](2차/시각자료/02_transfer_learning_explained.png): ImageNet에서 시작한 EfficientNet 특징 추출기 뒤에 질환 분류층을 붙였다. Hair·Web Skin의 Stage 1은 본체를 고정하고 새 분류층을 15 epoch 학습했다. Stage 2는 후반 30개 층 중 BatchNormalization을 제외한 부분을 열고 학습률을 `1e-4`에서 `1e-5`로 낮춰 10 epoch 더 학습했다. Skin Clean 원본·증강 비교는 별도의 head-only 15 epoch 실험이므로 Stage 2로 표시하지 않는다. 근거는 [EfficientNet 논문](https://proceedings.mlr.press/v97/tan19a.html)과 [Keras 전이학습 가이드](https://keras.io/guides/transfer_learning/)다.
- [무엇을 바꿔 봤나](2차/시각자료/02_optimization_methods_explained.png): 해상도 224→256, Label Smoothing 0.05, Focal Loss γ=1.5, B0→B1, Hair Stage 2 연장이라는 서로 다른 질문을 구분한다. 해상도·모델 규모는 [EfficientNet](https://proceedings.mlr.press/v97/tan19a.html), 라벨 스무딩은 [Szegedy 등의 Inception 연구](https://arxiv.org/abs/1512.00567), Focal Loss는 [Lin 등의 원논문](https://arxiv.org/abs/1708.02002)을 참고했다. Focal 원논문의 과제는 물체 탐지이며, MediFlow는 손실 아이디어를 분류에 응용했다. +5 epoch는 별도 논문 모델이 아니라 Hair v1 후보의 미세조정 연장이다. 도메인마다 효과가 달랐으며 모든 방법을 동시에 더한 하나의 모델로 설명하면 안 된다.

## 3차 Hair 그림

[Hair 논문 방법 지도](3차/시각자료/03_hair_paper_methods_explained.png)는 같은 Hair 5종 과제에서 시험한 방법을 나열한다.

| 방법 | 참고 자료 | MediFlow에서 실제로 한 일 | 관찰 |
|---|---|---|---|
| SupCon | [Khosla 등, Supervised Contrastive Learning](https://papers.neurips.cc/paper_files/paper/2020/hash/d89a66c7c80a29b1bdbab0f2a1a94af8-Abstract.html) | B1·256에서 라벨을 이용한 표현 학습 15 epoch 후 분류기 15 epoch | 비교 기준선보다 Validation Macro F1 상승; 최종 v2보다 낮음 |
| DINOv2 Small | [Oquab 등, DINOv2](https://arxiv.org/abs/2304.07193) | 224 입력, 영상 인코더 고정, 선형 분류층만 학습 | 이 고정 인코더 설정에서는 기준선보다 낮음 |
| EfficientNetV2-S | [Tan·Le, EfficientNetV2](https://proceedings.mlr.press/v139/tan21a.html) | 256 입력, 분류층 학습 후 부분 미세조정 | Hair Validation에서 미채택 |
| B1·384 | [Tan·Le, EfficientNet](https://proceedings.mlr.press/v97/tan19a.html) | 큰 입력에서 B1·Label Smoothing 0.05·Adam 조합 시험 | 단일 모델 Validation 선두, Hair 5종 v2 선정. v1과 순수 해상도 한 변수 실험으로 해석하지 않음 |
| SAM | [Foret 등, Sharpness-Aware Minimization](https://arxiv.org/abs/2010.01412) | B1·384에서 `rho=0.05`로 학습 | Adam과 Validation Accuracy 동률, Macro F1은 낮음 |
| 앙상블 | 두 저장 모델의 예측 평균을 검증한 프로젝트 실험 | SupCon·B1·384 예측을 1:1 평균 | 단일 B1·384보다 낮음; 새 모델 학습곡선 없음 |

## 3차 Web Skin 그림

[Web Skin 논문 방법 지도](3차/시각자료/03_web_skin_paper_methods_explained.png)는 얼굴 5종 사진에서 시험한 방법을 설명한다.

| 방법 | 참고 자료 | MediFlow에서 실제로 한 일 | 관찰 |
|---|---|---|---|
| WS-DAN 응용 | [See Better Before Looking Closer](https://arxiv.org/abs/1901.09891) | attention map 8개, 전체·확대 영역 예측 결합 | 기존 기준선보다 Validation 낮음 |
| PMG 응용 B0·256 | [Progressive Multi-Granularity Training](https://arxiv.org/abs/2003.03836) | 학습 시 8·4·2 조각 격자와 전체 경로, 추론 시 원본 한 장의 네 branch logits 합산 | Web Skin v2 선정 |
| MixStyle | [Domain Generalization with MixStyle](https://arxiv.org/abs/2104.02008) | 학습 중 얕은 특징의 통계를 섞음 (`alpha=0.1`, 적용 확률 `0.5`) | 기준선보다 Validation 소폭 높지만 PMG보다 낮음. 실제 웹캠 환경 일반화는 미검증 |
| PMG B1·384 | 같은 PMG 논문의 방법을 더 큰 모델·입력에서 비교 | B0→B1, 256→384, 배치 32→16이 함께 바뀜 | Validation 최고였으나 실행 비용을 고려해 B0·256을 전달 후보로 유지 |

MedSigLIP은 별도의 의료 영상 사전학습 표현 선별 실험이다. 이 네 장의 방법 그림에는 합치지 않았다. 세부 사항은 [3차 내용](3차/내용.md)의 MedSigLIP 절과 기존 별도 그림을 따른다. 서로 다른 도메인의 Validation 수치를 하나의 순위로 읽지 않는다.
