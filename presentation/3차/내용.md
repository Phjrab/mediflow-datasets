# 3차 · 논문 기반 방법 선별과 v2 후보

> 이 차수는 “논문에서 좋았으니 우리 모델도 좋아졌다”는 이야기가 아니다. **기존 분류기의 어떤 오류를 줄일지 가설을 세우고**, 논문 아이디어를 현재 코드에 맞게 구현한 뒤 **같은 도메인의 Validation**에서 확인했다. 성공·실패 실험을 모두 남기고, 선택한 후보만 Test로 최종 평가했다. 피부 현미경 `skin` 10종은 2차 v1을 유지해 이 차수의 새 모델로 세지 않는다.

## 연구 질문과 평가 원칙

2차 후에도 Hair의 비듬·미세각질처럼 닮은 표면 질감, Web Skin의 아토피·여드름·건선 같은 얼굴 질환 혼동이 남았다. Hair와 Web Skin을 **서로 다른 사진 과제**로 보고 맞는 가설을 따로 시험했다. 같은 도메인 안에서는 Clean 데이터와 Validation을 기준으로 비교하고, Test는 선택한 후보의 최종 평가에만 썼다. 논문은 **방법의 근거**이지 논문 벤치마크 성능을 우리 데이터에 보증하는 자료가 아니다.

해상도 확대 가설은 EfficientNet의 입력 크기 설계와 [피부 병변 다중 해상도 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC7150512/)를 참고했다. MediFlow는 해당 논문의 앙상블을 그대로 재현한 것이 아니라 **작은 특징 보존이라는 연구 질문**을 B1·384 후보로 시험했다. [실험 CSV](논문_실험표.csv)는 원본 결과 JSON의 수치를 담는다.

## 의료 영상 사전학습 표현: MedSigLIP-448 선별

[MedSigLIP 모델 카드](https://developers.google.com/health-ai-developer-foundations/medsiglip/model-card)에 제시된 의료 영상 표현이 ImageNet 기반 분류기보다 유리할지 확인했다. 본체를 **고정(frozen)**하고 각 사진의 embedding을 만든 뒤 새 Linear 분류층을 학습한 선별 실험이다. 새 전이학습 후보로 비교했으며 **최종 후보로 패키징하지 않았다.** 저장된 분류층만으로는 독립 추론이 불가능하고 외부 MedSigLIP 본체·전처리도 필요하다.

### 그림 설명

방법 자체를 설명할 때는 [Hair 논문 방법 지도](시각자료/03_hair_paper_methods_explained.png)와 [Web Skin 논문 방법 지도](시각자료/03_web_skin_paper_methods_explained.png)를 먼저 사용한다. 두 그림은 각 논문의 핵심 아이디어, 이번 코드에서 시험한 설정, Validation에서의 판단을 나란히 놓는다. 앙상블과 PMG B1·384는 새로운 원논문 방법이 아니라 후속 비교 실험임을 구분했다. 논문 원문 링크와 구현 범위는 [방법·논문 그림 해설](../방법_논문_그림_설명.md)을 따른다. MedSigLIP은 기존 별도 자료를 유지한다.

발표용 핵심 그림은 2차와 같은 구성의 **네 장**이다. Hair는 [전체 학습곡선](시각자료/hair5__all_paper_training_curves.png)과 [모델 성능 비교](시각자료/hair5__paper_model_performance_dashboard.png), Web Skin은 [전체 학습곡선](시각자료/web_skin__all_paper_training_curves.png)과 [모델 성능 비교](시각자료/web_skin__paper_model_performance_dashboard.png)를 사용한다. 학습곡선은 실험별 Accuracy·Loss를 나란히 보여준다. 성능 비교는 Validation Accuracy·Macro F1, 클래스별 Validation F1, **선정 모델만** 고정 Test 결과를 보여준다. 정확한 값은 저장된 결과 JSON과 [실험 CSV](논문_실험표.csv)에서 가져왔다. Hair 앙상블은 저장 모델의 예측을 합친 것이어서 독립 학습곡선이 없다. MedSigLIP은 별도 선별 실험으로 네 장에서 제외했다.

이전에 만든 `hair5__paper_experiments_overview.png`와 `web_skin__paper_experiments_overview.png`는 발표용 추천 그림에서 제외했다. 두 그림의 오분류 사진·혼동행렬이 위 네 장의 학습·성능 비교 목적과 섞여 보이기 때문이다. 원본은 보존한다.

원본 `results/`에 있는 Hair `supcon_performance_dashboard`, `paper_suite_dashboard`, `sam_performance_dashboard`를 부록에 순서대로 배치하면 가설 선별에서 최종 B1·384 채택까지 설명하기 좋다. Web Skin `paper_method_performance_dashboard`는 세 방법 비교, `pmg_scale_performance`는 B0·256 대 B1·384 비교다. MedSigLIP 두 `vs_*_validation` 그림은 **Validation 선별 결과**다. 두 최종 `final_test_confusion_matrix` 원본은 `results/`에 보존돼 있다. 선택을 고정한 뒤의 Test 결과이며, 발표 폴더의 네 장짜리 주요 비교 그림에는 넣지 않았다.

## 먼저 실험 기준을 어떻게 잡았나

Hair는 정제한 같은 5종 데이터에서, Web Skin은 확인된 같은 얼굴 5종 데이터에서 비교했다. Validation은 방법과 체크포인트를 고르는 데 사용하고 Test는 최종 후보를 고정한 뒤 평가했다. Hair의 SupCon 비교에는 **같은 시기·같은 코드의 B1·256 분류 기준선**을 함께 학습했다. 기존 v1의 숫자만 가져오면 데이터 버전은 같아도 학습 구현·실행 시점의 차이가 섞일 수 있기 때문이다. 이 새 기준선은 ‘새로운 공개 후보’가 아니라 SupCon 효과를 공정하게 읽기 위한 대조군이다.

Hair의 새 기준선 Val Accuracy `0.7755591054313099`, Macro F1 `0.7746028470442391`과 Web Skin 기존 B0·256·CE 기준선 Val Accuracy `0.796`, Macro F1 `0.7915394647566528`을 출발점으로 놓았다. Web Skin 기준선은 이미 저장된 같은 데이터 해시 결과를 재사용했으며 이번 세 방법 실행에서 새로 학습하지 않았다. 이처럼 **새 측정과 과거 저장 결과**를 구분해야 비교표의 의미가 정확하다.

## Hair: 각각 무엇을 보고 왜 시험했나

### 1. SupCon — 비슷한 두피 클래스의 특징 거리

[Supervised Contrastive Learning](https://papers.neurips.cc/paper_files/paper/2020/hash/d89a66c7c80a29b1bdbab0f2a1a94af8-Abstract.html)은 정답 라벨을 이용해 같은 클래스의 특징 표현은 가깝게, 다른 클래스는 멀게 배치한다. Hair에서 특히 **미세각질과 비듬**은 RGB 사진만 보면 둘 다 하얀 조각 패턴을 보일 수 있었다. 분류층의 경계만 조정하는 대신, 사진이 놓이는 **특징 공간 자체**를 분리해 보면 도움이 될 것이라는 가설이었다.

우리 구현은 B1·256에서 사진의 두 view를 사용한 표현 학습 15 epoch 뒤 분류기를 15 epoch 학습했다. 같은 기준선과 비교한 SupCon Val Accuracy `0.7915335463258786`, Macro F1 `0.7910880666407202`로 기준선 Macro F1 `0.7746028470442391`보다 높았다. 다섯 클래스 F1이 모두 상승했고 미세각질↔비듬 양방향 혼동이 **74→69건**으로 줄었다. 이것은 우리 설정에서 실제 이득이 있었음을 보여준다. 다만 이후 B1·384 단일 모델의 Macro F1 `0.7957146810115047`보다 낮아 최종 공개 후보로 선택하지 않았다. [SupCon 실행 보고서](../../docs/research/HAIR_SUPCON_RESULT_20260917.md).

### 2. DINOv2 Small — ImageNet CNN과 다른 사전학습 표현

[DINOv2](https://arxiv.org/abs/2304.07193)는 라벨 없이 대규모 이미지의 범용 시각 표현을 배운다. 기존 ImageNet CNN과 다른 표현이 두피 미세 질감에 유리할지 확인했다. 이 실험에서는 DINOv2 Small 인코더를 **고정**하고 224 입력의 새 선형 분류층만 15 epoch 학습했다. Val Accuracy `0.7699680511182109`, Macro F1 `0.7705341251195019`로 Hair 기준선보다 낮았다. 이는 **224·고정 인코더·Linear Probe** 설정의 결과이며, DINOv2를 미세조정했을 때의 성능이나 다른 의료 데이터에서의 능력을 부정하는 결과가 아니다. [남은 방법 선별 보고서](../../docs/research/HAIR_REMAINING_METHODS_RESULT_20260917.md).

### 3. EfficientNetV2-S — 새 CNN 계열의 전이 가능성

[EfficientNetV2](https://proceedings.mlr.press/v139/tan21a.html)는 학습 효율을 고려해 설계된 CNN 계열이다. B1과 다른 구조가 두피에서 더 좋은 특징을 배울지 시험했다. 우리 실험은 입력 256에서 head 학습과 부분 미세조정을 포함했다. Val Accuracy `0.7691693290734825`, Macro F1 `0.7681559382466019`로 기준선보다 낮아 미채택했다. 논문의 일반적인 효율 주장과 **이 Colab 실행에서의 Hair 검증 점수**는 서로 다른 주장이다.

### 4. B1·384 — 작은 각질 신호를 덜 축소하기

2차에서 B0 224→256은 Hair에 유리했지만 B0→B1만으로 큰 이득이 나오지 않았다. 그래서 “더 큰 본체”보다 **입력의 작은 질감 보존**을 핵심 질문으로 삼았다. [EfficientNet의 해상도 설계](https://proceedings.mlr.press/v97/tan19a.html)와 [피부 병변 다중 해상도 연구](https://pubmed.ncbi.nlm.nih.gov/32292713/)는 이 가설을 검토할 이유였다. MediFlow는 해당 피부 병변 논문의 전체 앙상블을 재현하지 않았다.

B1·384·Label Smoothing 0.05·Adam은 Val Accuracy `0.7963258785942492`, Macro F1 `0.7957146810115047`로 단일 모델 선두였다. Test 1,252장에서는 Accuracy `0.8003194888178914`, Macro F1 `0.8002222282821301`이었다. 5종 v1의 같은 Test Accuracy `0.7883386581469649`, F1 `0.7885764577048346`보다 높았다. 하지만 두 모델의 모든 학습 경로가 해상도만 다른 엄격한 단일 변수 실험은 아니므로 **B1·384 조합의 실증 결과**라고 설명한다. Test에서 비듬 F1 `0.75`, 미세각질 F1 `0.7807692308` 수준으로 어려운 클래스가 여전히 남았다. [최종 패키지 분석](../../docs/research/HAIR_FINAL_CANDIDATE_V2_20260921.md).

### 5. SAM과 앙상블 — 선두 모델을 더 개선할 수 있는가

[SAM](https://openreview.net/pdf?id=6Tm1mposlrM)은 현재 한 점뿐 아니라 주변 파라미터에서도 손실이 낮은 방향을 찾는다. 데이터가 조금 달라져도 덜 예민할지 B1·384의 Adam과 비교했다. `rho=0.05`를 쓴 SAM의 Val Accuracy는 같은 `0.7963258785942492`, Macro F1은 `0.7954748920799393`으로 Adam보다 낮았다. 미세각질↔비듬 혼동은 **71→68건**으로 감소했지만 다른 클래스 F1이 낮아졌고 계산 경로도 복잡해 최종 후보를 바꾸지 않았다. [SAM 세부 기록](../../docs/research/HAIR_SAM_RESULT_20260921.md).

앙상블은 SupCon과 B1·384의 softmax 출력을 **1:1 평균**해 오답이 서로 보완되는지 확인했다. 두 모델 중 하나라도 맞힌 Validation 사진은 1,052장이어서 결합 가능성이 있어 보였지만, 실제 평균의 Accuracy `0.7947284345047924`, Macro F1 `0.7942285283566071`은 B1·384 단일보다 낮았다. **최선의 두 모델을 합치면 항상 더 좋아지는 것은 아니다.** 두 모델을 모두 로드해야 하는 비용도 있어 미채택했다. [오답 보완성 기록](../../docs/research/HAIR_CANDIDATE_COMPLEMENTARITY_20260921.md).

## Web Skin: 얼굴 전체 속 중요한 부분과 환경 차이

### 1. WS-DAN — 중요한 부위를 자동으로 찾아 확대

[WS-DAN 원논문](https://arxiv.org/abs/1901.09891)은 attention map으로 구분에 유용한 위치를 찾고, 그 위치를 확대하거나 일부를 가리며 학습하는 세밀 분류 방법이다. 얼굴 사진에서 특정 질환의 단서가 눈·입·머리카락 같은 주변이 아니라 피부 부위에 있는지 보려는 가설이었다. 우리 응용 구현은 **attention map 8개**를 만들고 원본·attention 확대 영역의 예측을 결합했다. Val Accuracy `0.764`, Macro F1 `0.7546949301321499`로 기존 B0·256·CE의 `0.796`/`0.7915394647566528`보다 낮았다. 이는 현재 attention 설정과 데이터에서의 결과다. 원논문 기법 전체의 실패로 일반화하지 않았다.

### 2. PMG — 전체 얼굴과 여러 크기의 국소 질감

[PMG 원논문](https://arxiv.org/abs/2003.03836)은 다양한 크기의 jigsaw 조각을 단계적으로 학습해 세밀한 부분과 전체 특징을 융합한다. 건선·아토피·여드름이 얼굴에서 비슷한 분포를 보여도 피부의 국소 질감과 병변 크기는 다를 수 있다는 가설을 시험했다. 우리 코드는 **8·4·2 격자**의 조각 경로와 전체 경로를 활용했다. 실제 사용에서는 사진을 별도로 네 번 찍지 않고 **원본 얼굴 사진 한 장**을 입력한다. 네 branch의 logits를 **합산한 뒤 softmax**하는 출력 규칙은 패키지 전처리 계약에 들어 있다.

PMG B0·256은 Val Accuracy `0.85`, Macro F1 `0.8473279632397033`으로 기준선보다 각각 `+0.054`, `+0.0557884984830505` 높았다. Validation 500장의 오분류는 **102→75장**으로 줄었고 다섯 클래스 F1이 모두 상승했다. 특히 아토피·여드름 개선이 의미 있었다. 선택한 이 모델만 Test 400장에서 최종 평가해 Accuracy `0.915`, Macro F1 `0.9141049081029712`를 얻고 Web Skin **v2**로 패키징했다. 원 논문과 프로젝트 구현은 완전히 동일하지 않으므로 ‘PMG 아이디어의 응용’이라고 표현한다. [세 방법 비교 보고서](../../docs/research/WEB_SKIN_PAPER_METHOD_RESULT_20260922.md).

### 3. MixStyle — 얼굴 사진의 조명·색감 변화

[MixStyle](https://arxiv.org/abs/2104.02008)은 학습 중 feature의 평균·표준편차를 다른 이미지와 섞어 보지 못한 스타일을 간접적으로 만든다. 웹캠·조명·화이트밸런스가 달라도 질환의 형태를 보도록 하려는 가설이었다. 우리 설정은 EfficientNet의 얕은 특징 경로에 `alpha=0.1`, 적용 확률 `0.5`를 사용했다. 추론 시에는 섞는 단계가 없다. Val Accuracy `0.806`, Macro F1 `0.8033767539683495`로 기준선보다 소폭 높았지만 PMG에는 미치지 못했다. 다른 웹캠에서의 강건성은 **실제 장비 사진 없이 확인하지 못했다.**

### 4. PMG B1·384 — 성능 1위인데 왜 배포 후보가 아닌가

PMG가 유망했으므로 더 큰 backbone과 384 입력을 결합해 작은 단서가 더 잘 보이는지 시험했다. GPU 메모리 때문에 배치 크기 **32→16**도 함께 바뀌었다. 따라서 B0·256과 비교해 B1만의 효과 또는 해상도만의 효과를 따로 계산할 수 없다. Val Accuracy `0.866`, Macro F1 `0.8643216544321994`로 B0·256보다 높아 **연구상 Validation 선두**였다. 그러나 입력 픽셀은 2.25배, 모델 크기와 학습 시간이 증가했다. 이미 후보를 선택하던 때에 실행 비용을 고려해 B0·256을 v2로 고정했고, 뒤의 4차 Colab 측정은 B1·384의 p50 `419.9053944998923 ms`, B0·256의 `304.2439384998943 ms`를 기록해 비용 차이를 구체화했다. 이는 같은 Colab 환경의 지연 비교이지 실제 웹캠 전체 처리 시간은 아니다. [규모 비교 보고서](../../docs/research/WEB_SKIN_PMG_B1_384_RESULT_20260923.md).

## MedSigLIP: 의료 사전학습 표현을 선별한 이유

ImageNet 기반 EfficientNet과 달리 [MedSigLIP-448 모델 카드](https://developers.google.com/health-ai-developer-foundations/medsiglip/model-card)의 의료 영상 표현이 질환을 더 잘 분리할 가능성을 확인했다. 그러나 모델 전체를 의료 데이터로 미세조정한 실험이 아니다. **영상 인코더를 고정하고 embedding을 추출해 선형 분류층만 학습**한 Linear Probe였다. 두 도메인 모두 원본 Validation에서 결과를 봤고 Test는 열지 않았다. Web Skin은 Augmented Train 7,200장·원본 Validation 500장, Hair는 Augmented Train 15,047장·원본 Validation 1,252장이었다. 선형 분류층 학습은 AdamW 최대 50 epoch 설정이었다.

Web Skin MedSigLIP Accuracy `0.824`, Macro F1 `0.8195774288599683`은 PMG v2 `0.85`/`0.8473279632397033`보다 낮았다. Hair Accuracy `0.7699680511182109`, Macro F1 `0.7687534259685547`도 B1·384 v2보다 낮았다. 일부 혼동은 줄었지만 평균 성능이 개선되지 않아 **두 모델 모두 최종 선정·패키징하지 않았다**. 특히 저장된 작은 선형층 파일만으로는 추론할 수 없다. 실제 사용에는 큰 MedSigLIP 본체와 전처리도 함께 필요하다. 이 실험이 확인한 것은 **고정 특징의 선형 분리 가능성**이며 full fine-tuning의 결과가 아니다.

## 발표에서 결론을 어떻게 말할까

Hair에서는 SupCon의 유사 클래스 표현 분리 이득이 있었지만 최종 단일 후보는 B1·384였다. Web Skin에서는 PMG B0·256이 분류 성능과 실행 비용을 함께 고려한 v2가 됐다. 다른 방법이 낮았다는 사실도 중요한 결과다. 논문을 적용했다는 이유만으로 채택하지 않고 **우리 Validation에서 확인한 효과**로 결정했다. 서로 다른 도메인의 Test 숫자를 더하거나 순위로 놓지 않는다. Skin은 이 단계에 다시 학습하지 않았다는 사실도 구분한다.

> “Hair는 작은 두피 질감을 더 보존하는 입력과 유사 클래스 표현을 따로 시험했고, 384 입력 B1이 최종 선두였습니다. Web Skin은 얼굴의 국소 특징을 여러 크기로 배우는 PMG가 선두였으며, 더 무거운 384 모델 대신 실행 비용을 고려해 B0·256을 전달 후보로 선택했습니다. 모든 결론은 공개 데이터의 해당 Validation·Test에 한정됩니다.”
