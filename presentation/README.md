# MediFlow 발표·보고서 자료실

작성 기준: 2026-09-28. 기존 `docs/`, 전처리·학습 코드, `results/`의 보고서·그림·선정 모델을 대조해 시기별로 묶었다. 이 폴더의 그림과 모델은 **복사본**이며 원본은 기존 위치에 보존했다. 발표 시 `Test`는 모델 선택 후 최종 평가, `Validation`은 모델 선택에 사용했다는 점을 구분한다.

그림의 원본 경로는 [시각자료 출처표](시각자료_출처.csv)에 있다. 각 단계 `시각자료/`는 PPT에 붙일 수 있는 PNG 복사본이다. **서로 다른 도메인의 정확도를 모델 성능 우열로 비교하지 않는다.** Skin, Web Skin, Hair는 입력 장비·사진·클래스·평가셋이 다르다. Hair 5클래스와 6클래스도 전체 지표를 직접 증감률로 비교하지 않는다.

실제 실험 결과와 발표 그림의 포함 여부는 [시각자료 검증 기록](시각자료_검증_20260928.md)에 정리했다. 출처표는 현재 있는 PNG 47장에 맞춰 갱신했으며, 모든 원본 개별 그래프를 이 폴더에 복사한 것은 아니다.

발표 순서를 빠르게 잡을 때는 [슬라이드 구성안·지표 설명](발표_구성_안내.md)을 먼저 보고, 근거 파일을 추적할 때는 [원본 자료 찾아보기](원본자료_찾아보기.md)를 사용한다. 각 차수의 CSV는 표와 그래프를 다시 만드는 데 쓸 수 있고, PNG는 바로 삽입할 수 있다.

첨부된 예전 장문 보고서처럼 **왜 했는지·실제 방법·얻은 결과·한계**를 각 차수 `내용.md`에 상세히 풀었다. `docs/` 60개 파일의 제목·시기별 [검토 목록](문서_검토_목록.csv)과, 서로 다른 시기의 기록을 합칠 때 주의할 [차이점 정리](문서_검토_노트.md)도 추가했다.

**현재 검증 범위:** 공개 데이터의 저장 결과와 Colab GPU에서의 합성 이미지 실행 시간이다. USB 현미경·웹캠 실제 촬영 사진의 일반화 성능, Jetson 지연·메모리·전력, 환자 단위 임상 성능은 측정하지 않았다. 초기 원본 데이터셋이 보존되지 않아 초기 6개 모델의 옛 Test 사진을 다시 추론하는 재현도 완료되지 않았다.

한 파일로 읽는 전체 서술은 [최종 상세 보고서](../docs/FINAL_DETAILED_REPORT_20260928.md)에 있다. 실행별 근거는 [Hair 5→6 분석](../docs/research/HAIR_5CLASS_6CLASS_EXPERIMENT_ANALYSIS_20260928.md), [실행 비용 검토](../docs/research/RUNTIME_BENCHMARK_REVIEW_20260928.md), [실행 로드맵](../docs/ROADMAP.md)에서 확인한다. 과거 계획서의 제안과 실제로 완료한 실행을 혼동하지 않도록 본 폴더에서는 결과가 확인된 작업만 완료형으로 썼다.
