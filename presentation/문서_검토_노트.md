# 기존 문서를 합치며 확인한 시점·수치 차이

[문서 60개 목록](문서_검토_목록.csv)은 정리 **이전** `docs/`의 Markdown 제목·시기·발표 차수를 찾기 위한 스냅샷 색인이다. 2026-09-28에 과거 문서 13개를 [보관 ZIP](../docs/zip/README.md)으로 옮겼고, 이후 중복 안내 파일도 정리해 일부 원래 경로는 현재 존재하지 않는다. 현재 문서 경로는 [docs 안내](../docs/README.md)와 [results 안내](../results/README.md)를 따른다. 이 CSV는 제목과 경로로 분류한 **찾아보기용 과거 표**이며, 개별 주장의 사실 여부는 아래 우선순위와 실제 `results/` JSON·CSV·패키지에서 확인한다. 첨부된 다운로드 폴더의 `MEDIFLOW_PROJECT_FINAL_REPORT_20260914.md`는 저장소의 같은 이름 파일과 내용·SHA-256이 다르다. **설명 구성의 참고본**으로 사용했고, 이후 완료 상태는 저장소의 최신 결과로 갱신했다.

## 어느 기록을 우선했나

1. **정확한 성능·모델 파일:** `results/`의 실행 JSON·CSV, 후보 ZIP·`selection.json`, [최종 모델 선정](../results/FINAL_MODEL_SELECTION_20260928.md). 표의 화면용 자릿수를 줄여도 원본 값은 이 파일에 남아 있다.
2. **현재 완료·미완료 범위:** [프로젝트 현재 상태](../docs/PROJECT_STATUS_20260928.md)와 [실행 로드맵](../docs/ROADMAP.md). 과거 계획 문서의 ‘미실행’ 표기는 작성 당시 상태다.
3. **실험 이유와 방법:** [전체 실험 대장](../docs/research/ALL_EXPERIMENTS_RATIONALE_AND_RESULTS_20260924.md), 도메인별 상세 결과, 전처리·학습 코드. 논문이 제안한 원리와 MediFlow의 실제 구현을 분리해 적었다.
4. **과거 원천·초기 기록:** [프로젝트 배경](../docs/research/PROJECT_BACKGROUND.md), [원천 클래스표](../docs/presentations/DATA_SOURCE_CLASS_TABLE.md), 첨부한 2026-09-14 보고서. 원본 데이터 ZIP이 없어 당시 수량을 새로 계수한 것은 아니다.
5. **`docs/zip/HISTORICAL_DOCS_20260928.zip`:** 당시 계획·중간 분석·검증 과정의 흔적을 원문 그대로 보관했다. 실제 실행 완료와 현재 선택 모델을 판단하는 우선 자료로 사용하지 않았다.
