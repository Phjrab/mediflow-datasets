위 수치는 완료된 실험의 보고값을 그대로 보존한 것으로 새 평가가 아닙니다.
범위 밖 입력 거부 기능은 포함하지 않습니다.

모델 출력은 보정되지 않은 점수입니다. 자세한 계약은 preprocessing.json을 보세요.
