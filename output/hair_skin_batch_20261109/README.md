# MediFlow Hair · Skin 분석을 한 번에 실행

GPU를 선택하고 **런타임 → 모두 실행**을 누르세요. 파일 선택 창에서 기존 `mediflow_da_runtime.zip` 하나를 선택하고 Drive를 연결하면 됩니다. 코드나 DOMAIN을 수정할 필요 없습니다.

순서: **실행 ZIP 업로드 → 환경 확인 → Hair 5클래스 분석·미리보기 → Skin 10클래스 분석·미리보기 → 분야별 결과 ZIP 2개 다운로드**. 기본 Colab 환경이 맞지 않으면 별도 분석 환경을 자동으로 설치합니다. Colab 기본 TensorFlow를 교체하지 않아 2.21/2.20 패키지 충돌을 피합니다. 호환 환경에서는 설치를 반복하지 않습니다.

학습·REVIEW_NOTE·최종 Test 평가 단계는 포함하지 않습니다. 중복·분할 검사는 수행하고, 미해결 항목을 결과에 보존합니다. 일반 참여자 사진의 정답과 Target 정확도를 만들지 않습니다.

결과는 Drive 내 드라이브의 `mediflow_da_hair_skin_…/hair`, `…/skin`에 각각 보관합니다. 다운로드가 차단되면 브라우저의 여러 파일 다운로드를 허용하거나 마지막 다운로드 버튼을 누르세요. 실패한 분야는 `mediflow_failed_…zip`으로 구분되며 로그를 포함합니다. 실제 촬영 원본은 실행 ZIP에 포함되어 있지 않습니다.
