# MediFlow 시험 촬영 도구 사용법

> 2026-11-11 정리 상태: **안내·기준 문서, 자체가 학습 완료 근거는 아님**. [현재 작업 안내](../../README.md) · [전체 문서 대조표](../../DOCUMENT_INDEX.md). 아래 본문은 작성 시점 기록이며, 본문·원본 JSON의 이전 경로는 정리 대조표로 추적한다.

Windows 탐색기에서 [start_camera_pilot.cmd](../../../scripts/start_camera_pilot.cmd)를 두 번 클릭한다. 현재 MediFlow의 Python 환경으로 촬영 창이 열린다.

이번 시험 촬영은 **4명(`P01`~`P04`) × 3분야 × 10장 = 총 120장**으로 진행한다. 사람마다 피부·두피·얼굴을 각각 평소 조명(`기준`)에서 5장, 조명을 조금 바꾼 상태(`변경`)에서 5장씩 찍는다. 분야별로 40장이고, 전체는 기준 60장과 변경 60장이다. 같은 사람의 첫 촬영은 세 분야 모두 `S01`을 사용한다.

1. **카메라 확인.** 현재 DirectShow에서는 `3번 HD Pro Webcam C920`과 `2번 USB 2.0 Camera`에서 영상이 들어오는 것을 확인했다. `web_skin`은 3번, `skin`·`hair`는 2번에서 **미리보기 시작**을 누른다. DirectShow에서 미리보기를 시작하면 Windows의 장치 이름이 자동으로 채워진다. USB 재연결이나 연결 방식 변경 후에는 번호가 달라질 수 있으므로 화면에서 실제 장비를 확인한다.
2. **설정 기록.** 해당 참여자 번호와 `S01`을 선택하고 촬영 부위를 적는다. 카메라 이름과 조명·거리·배율·초점·노출·색은 선택 입력이다. 도구는 얼굴 1280×720, 현미경 640×480을 요청하며, 실제 해상도는 화면에 표시된다. 한 분야의 기준·변경 사진은 같은 장비와 해상도를 사용한다.
3. **조건별로 5장씩 촬영.** `기준`에서 5장을 찍고, 같은 사람·부위·구도를 유지하면서 조명을 한 번 바꾼다. `변경`을 선택하고 바뀐 조명을 짧게 메모한 뒤 5장을 더 찍는다. 분야별 10장으로 조건별 사진의 특성을 비교한다. 다른 분야에서는 다시 `기준`부터 시작한다. 초기 촬영은 이 방식을 사용하고, 사진을 한 장씩 대응시켜 비교할 때는 별도로 쌍을 기록한다. [촬영 가이드라인](CAMERA_ADAPTATION_GUIDELINE_20261108.md).
4. **저장 확인.** MediFlow 프로젝트의 `camera_capture` 아래 `분야\참여자\촬영 세션`에 사진 PNG와 같은 이름의 촬영 기록 JSON이 저장된다. 촬영 창 아래에 표시된 저장 위치를 탐색기 주소창에 붙여넣어 확인한다. `camera_capture`는 Git에서 제외한다. 다시 찍으면 시각이 다른 이름으로 저장되므로, 분석할 때 사용할 사진을 따로 표시한다.

다른 앱에서 카메라를 사용 중이라면 닫고 다시 시작한다. 영상이 계속 열리지 않으면 `연결 방식`을 `Media Foundation`으로 바꿔 다시 확인한다. 창을 닫거나 **중지**를 누르면 카메라 사용을 끝낸다.
