## 발견한 문제와 수정

### 비교용 검증 이미지의 디스크 공간 계산

기존 입력 캐시 검사는 원본·새 조명·새 확장 검증 배열까지 계산했지만, 그 다음 추가로 생성하는 기존 2차 변환 검증 배열을 빠뜨렸다. 공간이 경계에 걸리면 뒤늦게 실패할 수 있었다.

원본 Train + 원본 Validation + 새 조명 Validation + 새 확장 Validation + 기존 변환 Validation을 모두 포함하도록 사전 검사했다. ZIP은 별도로 복사하므로 시작할 때 ZIP 크기도 더해 확인하고, 복사 후에는 실제 남은 공간에서 전체 캐시와 1 GiB 여유를 다시 확인한다. 입력 자료는 메모리 매핑 파일로 보관하고 세 분야의 캐시는 순서대로 만들고 정리한다.

### 필요한 파일을 먼저 확인

환경 준비·데이터 ZIP 복사·학습 전에 세 분야의 출발 모델, 1·2차 완료 기록, 기존 비교 모델 해시, Source 분할 목록과 클래스 계약을 한 번에 확인하도록 했다. 필요한 Source ZIP도 미리 찾는다. 파일이 없거나 다른 실험의 결과이면 학습 전에 멈춘다. Source ZIP의 고정 해시·실제 이미지 중복·누수 검사는 로컬 복사 후 원래 절차대로 다시 실행한다.

검사 결과를 Drive의 `startup_preflight.json`에 남기고 결과 ZIP에도 포함한다. 이번 수정은 운영 검사이며 학습 손실·모델 선정·변환 함수·학습량 변경이 아니다. 기존 비교·그래프·CLI 함수의 구문도 이전과 같은지 대조했다.

## 현재 변환 강도

| 분야 | 이미 학습한 2차 대비 밝기 설정 | 현재 추가 색·미세 대비·흐림 |
| --- | --- | --- |
| 피부 | 약 −1에서 +32로 방향·폭 변경 | 작은 a 감소·b 증가, 추가 미세 대비·흐림 없음 |
| 얼굴 | 약 +13–18에서 −32로 방향 변경 | 작은 b 감소, 미세 대비 감소, 흐림 sigma 상한은 2차의 2배 |
| 두피 | 최대 약 +12에서 +15–26 범위로 확대 | 추가 색·미세 대비·흐림 없음 |

밝기 숫자는 0–255 척도의 이동 파라미터이며 실제 픽셀 변화는 부드러운 경계 제한 처리와 대비·색 처리의 영향을 받는다. 밝기가 해당 비율만큼 증가한다거나 전체 변환 강도가 일괄 두 배라는 뜻은 아니다. 피부·얼굴의 일부 밝기 범위는 제한에 걸려 한 값이다. 기존 2차와의 비교와, 보류한 이전 확대 후보에서 직전 수정본으로 바꾼 비교를 구분한다. 이번 직전 점검에서는 이 강도를 더 올리지 않았다.

## 남은 실행 조건

실제 Drive의 원본 ZIP·1/2차 결과와 Colab GPU는 새 실행의 첫 단계에서 검사한다. 로컬에 없는 전체 Source ZIP의 이미지 재검사는 여기서 수행했다고 보고하지 않는다. 사람·병변·세션 식별자가 없는 Source와 과거 모델의 평가 독립성 한계는 그대로 남는다.

기존 Test로 변환을 다시 고르지 않는다. 새 비교는 Validation을 사용하고 원본 성능 저하도 확인한다. 실제 촬영 124장은 정답 미확인 calibration 자료이므로 실제 장비 질환 분류 성능의 개선을 확정할 수 없다.

현재 단계는 학습 직전 검사 완료다. 사용자는 위 현재 노트북을 Colab에서 실행하면 된다.
