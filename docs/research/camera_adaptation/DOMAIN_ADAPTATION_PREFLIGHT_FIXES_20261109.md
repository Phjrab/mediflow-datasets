## 2. 새 입력·변환 후보의 의미

얼굴 Source는 정사각형이므로 중앙 정사각형 정책이 Source를 추가로 잘라내지는 않는다.
실제 웹캠의 가로로 긴 사진을 정사각형으로 눌러 변형하는 대신 중앙을 자르는 후보다.
현재 촬영 42장의 기록된 얼굴 상자는 모두 해당 범위 안에 있다. 주변 영역을 일부 제외하는
정책이므로 향후 촬영 구도와 실제 성능 검증은 필요하다.

같은 기존 얼굴 모델로 중앙 자르기 전후 실제 42장을 추론했을 때 최상위 예측이 15장에서
바뀌었다. **전처리만의 예측 변화이며 정답이 없어 개선 여부는 판단하지 않는다.**
이후 모든 비교군에 같은 입력 정책을 적용해 전처리 효과와 추가 변환 학습 효과를 혼동하지 않는다.

두피는 전체 그룹에서는 대비 감소 방향이 같았지만, 어두운 경계 비율이 겹치는 표본만 보면
P02의 대비 방향이 달라졌다. 이 보조 지표 자체가 모발 분할 정답은 아니지만, 현재 대비 차이를
조명 단독 효과라고 보기 어렵다는 민감도 근거다. 지금은 임의의 대비 변환을 넣지 않고
Source-only와 Brightness-only를 실행 후보로 남긴다. Target-guided는 동일 조건임을 기록한다.

이것은 두피의 도메인 차이가 해결됐다는 뜻이 아니다. 기존 자료로 근거 없는 변수를 추가하지
않고 중복 비교를 제거한 것이다. 색·질감·초점의 장비 효과 분리는 추가 근거가 필요하다.

Colab에서 새 노트북을 열고 GPU를 선택한 뒤 **모두 실행**한다. 새 실행 ZIP 하나를 선택하고
기존 데이터셋이 있는 Drive 계정으로 연결한다. DOMAIN이나 경로 수정은 필요 없다.
옛 실행 ZIP에는 이번 수정이 없으므로 새 ZIP을 사용한다. 옛 파일은 그대로 보존했다.

순서는 Web Skin → Hair → Skin이다. Source 전체 Train 통계는 검증된 기존 결과를 재사용하고,
원본 ZIP 해시·클래스·Train 목록을 다시 대조한다. 새 설정의 Target 측정값·특징은 PC에서
준비해 포함했다. 실제 촬영 원본은 Colab 업로드 ZIP에 넣지 않는다.

각 분야에서 수행하는 작업은 다음과 같다.

1. 원본 Train과 촬영 calibration 자료만으로 v2 프로필 생성. 승인 상태는 pending 유지.
2. 클래스당 고정 Train 표본 최대 24장으로 원본/변환/Target 분포와 전후 이미지 생성.
3. Web Skin의 얼굴 검출 실패 Train 552장에 대한 사진·목록 생성.
4. 기록된 원본·증강 이력으로 유사 후보를 묶고 더 높은 해상도로 비교 지표·사진 생성.
5. 클래스당 Source 특징 8장과 Target 전체의 특징 거리·PCA 재생성. 누락됐던 얼굴 진단도 보완.
6. 세 분야 결과와 실행 환경·로그를 ZIP 하나에 담아 다운로드하고 Drive에도 보관.

학습과 최종 Test 정확도는 이 노트북에 포함하지 않는다. Test 사진은 유사 후보의 동일 사례·
파생본 확인에만 사용하며 변환 강도 결정에는 사용하지 않는다. SSIM은 검토 순서를 정하는
보조값이고 동일 인물 판정이나 후보 자동 해제 기준으로 사용하지 않는다.

## 5. 검증과 실제 잔여 작업

`ruff check src tests` 및 새 생성기 검사 통과. 전체 pytest는 **148개 통과·3개 건너뜀·실패 0개**다.
3개는 기존 노트북 테스트의 선택 라이브러리 matplotlib 부재다. 작은 임의 모델·자료로
preflight 전체 경로를 실행했고 학습·Test 성능 평가가 호출되지 않음을 확인했다.
이 검사는 피부·두피 질환 실험이나 실제 Colab 전체 원본 검토가 아니다.

남은 작업은 다음과 같다.

- 사용자가 새 Colab을 실행해 Drive 원본 사진을 기반으로 검토 자료를 내려받는다.
- 후보 이미지·검출 실패 구도·변환 후 분포를 실제로 확인하고 판단 근거를 기록한다.
- 실제 누수가 발견되면 새 데이터 버전과 기준 모델 이력을 검토한다. 후보 수만으로 삭제하지 않는다.
- 검토한 실험 정책을 고정한 뒤 비교 학습·Validation 선정·최종 Source 평가를 진행한다.
- 정답 확인 실제 질환 사진이 생기기 전에는 실제 장비 정확도 개선을 주장하지 않는다.

사람·병변·세션 ID 부재는 코드로 복구한 것이 아니다. 확인 불가 범위를 계속 기록한다.
기존 네 참여자의 사진을 독립 Test로 재분할하거나 모델 예측을 정답으로 삼지 않는다.
