## 측정 방법

- 실제 촬영 124장과 기존 데이터 예시 20장을 읽었다. 볼의 위치를 확인할 수 없었던 웹캠 예시 한 장을 영역 수치에서 제외해, 분석 대상은 **실제 124장과 예시 19장**이다. 예시의 데이터 분할 소속은 확인되지 않았다. [데이터셋과 촬영 사진 비교](CAMERA_DATASET_EXAMPLE_COMPARISON_20261108.md).
- 저장 모델과 같은 방식으로 얼굴 256×256, 피부 224×224, 두피 384×384로 줄인 뒤 얼굴은 양쪽 볼, 현미경은 화면 중앙부를 비교했다. 실제 사진은 같은 참여자와 조건 안에서 요약한 후 기준·변경을 비교했다. 반복 사진을 새 참여자로 세지 않았다.
- **픽셀 분포**는 밝기의 하위 10%, 중앙, 상위 90% 위치와 아주 어둡거나 밝은 픽셀의 비율을 확인했다. **국소 대비**는 같은 볼이나 중앙부에서 상위 90% 위치와 하위 10% 위치의 차이다. **색**은 Lab의 빨강–초록(`a*`), 노랑–파랑(`b*`) 방향을 비교했다. Lab으로 바꾸기 위한 계산은 측정에만 썼다. 기존 모델에는 RGB `float32` 0–255를 유지한다.
- **미세 질감**은 영역을 같은 64×64 크기로 놓고 원래 밝기에서 부드럽게 흐린 밝기를 뺀 차이의 크기로 비교했다. 이 값은 피부 무늬뿐 아니라 모발 경계, 사진 속 대상 크기와 축소 과정의 영향도 받는다. 카메라 노이즈나 렌즈 선명도를 따로 재는 값은 아니다.

## 분야별 관찰 결과와 적용 판단

| 분야 | 이번 자료에서 확인한 것 | 묶음에 반영할 내용 |
|---|---|---|
| 웹캠 얼굴 | 볼 밝기 중앙값은 예시 약 **180**, 실제 기준 약 **82~103**, 실제 변경 약 **96~139**였다. 실제 변경은 기준보다 밝지만 예시보다는 어두웠다. 볼 안의 대비는 네 사람 모두 변경에서 **약 5~10** 높았다. 빨강–초록 방향의 변화는 작고 노랑–파랑 방향은 사람마다 달랐다. | 얼굴 크기·화면 비율, 밝기 수준, 볼 안의 대비와 한쪽 조명을 한 묶음으로 다룬다. 얼굴이 작게 들어가면서 세부 정보가 줄어드는 효과가 있으므로, 추가 흐림을 별도로 강제할 근거는 아직 부족하다. 전역 색 보정도 보류한다. |
| 현미경 피부 | 실제 사진 중앙부의 노랑 쪽 `b*`가 예시보다 높았고, 기준에서 변경으로 갔을 때는 방향이 섞였다. 대비는 네 사람 모두 변경에서 약 **2~5** 낮았다. 실촬영 팔 사진과 예시의 병변 사진이 보여주는 내용도 다르고, 일부 실촬영에서 표면이 흐렸다. | 약한 색감·대비·초점 변화를 함께 시험한다. 사진 사이 색 차이를 카메라 보정량으로 간주하거나 병변의 색을 실제 팔 사진에 맞춰 덮어쓰지 않는다. |
| 현미경 두피 | 실제 중앙부의 어두운 모발과 밝은 두피 사이 대비가 예시보다 컸다. 실제 사진의 미세 경계량도 더 큰 경우가 많았고, 동시에 일부 사진의 두피 표면은 흐렸다. | 약한 흐림과 국소적으로 밝은 영역을 함께 시험한다. 모발이 차지하는 비율이 섞인 대비·질감 차이를 전역 보정량으로 사용하지 않는다. 촬영에서는 가르마와 초점을 맞춘다. |

전체 측정값은 `camera_capture/_review/domain_shift_20261108/domain_shift_measurements.json`에 있다. 위 값은 이번 예시와 참여자에게서 관찰한 값이다. 색 차이를 실제 조명·센서 색 보정에 사용하려면 같은 설정에서 무채색 기준 물체를 찍는 등의 별도 비교가 필요하다. 환자 사진의 색이나 질감은 질환 특징 자체일 수 있으므로, 예시 전체의 색 분포를 참여자 사진에 일률적으로 맞추지 않는다.

## 수정한 변환 초안과 다음 검증

[변환 코드](../../../src/mediflow_datasets/camera_augmentation.py)의 `camera-bundle-preview-v2`에서는 Web Skin의 얼굴 크기·비율·한쪽 조명에 **전체 밝기를 낮추는 계수와 대비 조정**을 넣었다. Skin은 약한 색감과 흐림에 **작은 대비 변화**를 추가했다. Hair는 약한 흐림과 국소 조명을 함께 사용한다. 모든 변환은 분야별로 한 번에 적용한다.

예시 20장에 수정본을 적용해 기존 RGB 범위와 입력 크기, 같은 난수값에서의 재현성을 확인했다. 볼 비교가 가능한 얼굴 예시 4장은 볼 밝기가 모두 낮아졌다. 다만 변환 후 볼 밝기는 약 **116~162**, 볼 안 대비는 약 **10~24**였다. 일부 밝기는 실제 변경 범위보다 높고, 대비는 대부분 실제 변경 범위보다 낮았다. **이번 수정본은 변화 방향을 바로잡은 미리보기이며, 목표 분포를 맞춘 학습 설정은 아니다.** 얼굴 주위의 단순 배경도 남아 있다. 분할 소속이 불명확한 이 예시에 맞춰 강도를 추가 조정하지 않았다.

다음에는 기존 데이터 ZIP의 해시와 Train·Validation·Test를 대조한 뒤, **확인된 Train 사진만** 골라 변환 전후의 밝기·대비·색·세부 경계를 같은 방법으로 재측정한다. 질환을 가르는 색이나 형태가 손상되는 범위와 인위적인 배경 경계를 확인하고 강도를 정한다. 학습 비교에서 바꾸는 조건은 변화 묶음 사용 여부이며, 나머지 모델과 학습 조건은 맞춘다. Validation에서 설정을 고정한 뒤 원본 Test와 변환 Test 복사본에서 최종 비교한다. 실제 환자 촬영 성능은 정답이 확인된 별도 사진에서 평가할 수 있다.
