가지므로 바이트 동일 중복으로 분류하지는 않는다. 생성·촬영 출처를 증명한 것은 아니며
보수적으로 **유사 복제 우려**로 별도 기록했다.

두 쌍의 라벨은 Source 메타데이터상 흑색점이다. 이는 기존 라벨을 인용한 것이며 실제 촬영

원본 Train과 augmented Train의 복제본을 각각 세었다. 원본 데이터에서 삭제하거나 분할을

기존 피부 선정 모델은 해당 Train 이미지를 학습했을 가능성이 있다. 앞으로 추가 학습에서
두 장을 빼더라도 체크포인트의 과거 노출은 없어지지 않는다. 문제가 확인된 상태에서 깨끗한
평가를 하려면 검토한 Train으로 새 기준 모델부터 학습하거나 독립 평가 자료를 마련해야 한다.
기존 보고 성능은 보존하되, 이번 점검을 근거로 누수가 완전히 배제된 값이라고 설명하지 않는다.

얼굴 유사 후보 첫 5페이지와 피부 첫 페이지를 확인한 범위만 검토 기록에 남겼다. 웹캠 전체
159개·피부 전체 1618개를 정상 처리하지 않았다. 사람의 얼굴 생김새로 동일인 여부를 판정하지

- 기존 선정 모델 3개와 과거 노트북·실행 ZIP의 해시 보존 확인.
- Colab과 로컬의 결과·입력 정책·환경은 각각 기록했다. 로컬 비교 코드는 미커밋 상태이며
  기준 commit은 `ffd71eca68ff1e21c145ed56158f4cfa77f7f037`이다.
  실행 당시 변경 파일 SHA256은 `review_summary.json`에 기록했다.

적응 학습, 새 체크포인트 생성, Validation 성능 비교, Source Test 정확도 재평가,
Target 정확도 계산, Git commit/push는 실행하지 않았다. Target 질환 정답은 없으며
Target accuracy는 계속 `null`이다. 네 사람의 촬영 자료는 모두 calibration에 쓰였으므로
일부를 지금 독립 Target Test였던 것처럼 다시 명명하지 않는다.

1. 남은 이미지 파생 후보와 변환 비교 사진을 검토하고, 판단 근거를 별도 기록한다.

   과거 원본을 보존하며 검토된 제외 목록을 적용하는 새 버전과 새 기준선이 필요하다.

   Target-guided를 비교한다. 두피의 동일 조건은 한 번만 실행한다. 웹캠의 기존 전처리
   저장 모델과 중앙 자르기를 공유한 Source-only 기준선은 구분해서 기록한다.
