## 1. 어떤 실험을 실제로 했는가

| 구분 | 실제 학습 수 | 사진에 적용한 것 | 특징 정렬 손실 | 출발점 |
| --- | --- | --- | --- | --- |
| 원본 모델 | 새 적응 학습 없음 | 없음 | 없음 | 기존 저장본, 비교 기준 |

| 2차 | 세 분야 각 1회 = 3회 | 1차 조명 + 측정에 따른 Lab 색·미세 대비·흐림 | 없음 | 1차에서 고른 모델의 **1차 이전 저장본** |

**1→2→3→4차로 이어 학습한 것이 아니다.** 각 차수는 같은 기존 저장 모델에서 다시 시작해 조건을 비교했다. 현재 휴대폰 2차는 Lab a 변환이 추가되어 별도 학습한다. 과거 ‘2차를 재사용해 총 4회’ 안내는 최신 5회 계획으로 대체되었다.

중단한 초기 9개 통합 실행, 준비만 한 별도 학습안, 사용자 결정으로 실행하지 않은 ‘재설정 4차’는 완료 15회에 포함하지 않았다. 이 문서의 4차는 **실제로 완료한 조정 전 4차**다.

## 2. 밝기·대비·좌우 조명 조절값

1·2·3차의 조명값은 분야별로 동일하다. 2·3차에서 추가된 색·미세 대비·흐림은 다음 표에 별도로 적었다.

| 분야 | 실험 | 밝기 제안값 | 대비 배율 | 좌우 조명차 | 상태 |
| --- | --- | --- | --- | --- | --- |
| 현미경 피부 | 1·2·3차 | -1.349252 ~ -0.729245 | 0.93997 ~ 0.95735 | 0 | 완료 |
| 현미경 피부 | 4차 | 32 | 0.8 | 0 | 완료 |
| 웹캠 얼굴 | 1·2·3차 | 13.485409 ~ 17.610365 | 1.15 | 13.776814 ~ 15.418357 | 완료 |
| 웹캠 얼굴 | 4차 | -32 | 0.8 ~ 1.015297 | 24 | 완료 |
| 현미경 두피 | 1·2·3차 | -0.636374 ~ 12.45062 | 1 | 0 | 완료 |
| 현미경 두피 | 4차 | 15.043114 ~ 26.260809 | 1 | 0 | 완료 |
| 휴대폰 얼굴 | 1·2·3차 | -9.812065 ~ 0 | 1 ~ 1.090439 | -0.211193 ~ 0 | 학습 전 |
| 휴대폰 얼굴 | 4차 | -19.62413 ~ 0 | 1 ~ 1.180879 | -0.422386 ~ 0 | 학습 전 |

- 밝기 0은 추가 이동 없음이다. 양수는 밝게, 음수는 어둡게 하는 방향의 **RGB 가산 제안값**이다. 밝기 +32를 ‘밝기 32% 증가’로 쓰면 안 된다.
- 대비 1은 유지다. 0.8은 밝기 중간값에서 벗어나는 회색조 차이를 계산상 0.8배로 만드는 제안이다. 최종 측정 대비가 정확히 20% 줄어든다는 뜻은 아니다.
- 좌우 조명차 24는 변환 전 제안에서 왼쪽 +12, 오른쪽 −12의 기울기를 더한다. 0은 기울기 없음이다. 음수는 반대 방향이다.
- 모든 단계에서 x·y 크기 배율은 각각 `[1, 1]`이다. 확대·축소·얼굴 크기 보정·기하 변형은 이 실험에서 추가하지 않았다.

4차는 일괄 두 배 강화가 아니다. 피부는 약한 음의 밝기 이동에서 +32로 방향도 바꾸고 대비를 0.8로 낮췄다. 얼굴은 밝게 하던 설정을 −32로 바꾸고 좌우 조명차를 24로 늘렸다. 두피는 양의 밝기 범위를 높이고 다른 변환은 제거했다. **휴대폰 4차만** 1차 대비 밝기 범위·대비의 1에서 벗어나는 양·좌우 조명차를 각각 두 배로 넓힌 별도 계획이다.

Lab은 색을 밝기·적록·황청 성분으로 나누어 표현하는 좌표다. a 양수는 적색, 음수는 녹색 방향이고 b 양수는 황색, 음수는 청색 방향이다. 이 값은 RGB 채널 가산값이나 퍼센트가 아니다. 질환색 자체를 무조건 실제 촬영 참여자의 색으로 맞춘 것이 아니라, 분석에서 허용한 작은 촬영 외관 변화다.

미세 대비 1은 유지, 0.85는 회색조 고주파 잔차를 계산상 15% 줄이는 제안이다. 고주파 잔차는 원래 회색 영상에서 부드럽게 만든 영상을 뺀 세부 패턴이다. **질환 질감이 15% 감소했다는 뜻은 아니다.**

흐림 σ는 가우시안 흐림의 픽셀 단위 표준편차다. 2·3차 기준 ROI64→실제 입력 환산 배율은 피부 **1.75**, 얼굴 **1.9375**, 두피 **3**이다. 따라서 최대 입력 σ는 각각 **0.5250000000000001 / 0.3875 / 1.06875 px**다. 4차 얼굴은 최대 **0.775 px**이며 피부·두피는 0이다. 렌즈의 실제 초점 거리나 촬영 거리 mm와 직접 대응하지 않는다.

휴대폰은 현재 2·3차에서 **a = 0 ~ 1.0117187500000009**만 추가했다. b·흐림·미세 대비는 근접성 검토에서 채택하지 않았다. 4차는 별도 조명 확대 가설이며 이 색 이동을 포함하지 않는다. [휴대폰 재검토](SMARTPHONE_STAGE2_COMMON_NEARER_20261111.md)의 Lab a 분포 개선은 색 분포 비교 결과이며 질환 정확도 개선 결과가 아니다.

### 실제 픽셀 값이 표의 가산값과 다른 이유

조명 제안은 아래 방식이다. `gray`는 회색조 값, `median`은 이미지의 회색조 중앙값이다.

```text
조명 변화 제안 = 밝기값 + (gray − median(gray)) × (대비배율 − 1)
                 + 좌우조명차 × [왼쪽 +0.5 → 오른쪽 −0.5]
```

RGB가 0 또는 255에 몰리는 현상을 줄이도록 경계 보호 함수를 적용한다. 픽셀값을 x, 제안 변화량을 Δ라고 할 때:

```text
Δ ≥ 0: x' = x + (255 − x) × (1 − exp(−Δ / (255 − x)))
Δ < 0: x' = x × exp(Δ / x)
```

코드는 0·255 경계의 계산 보호와 float32 범위 보호도 포함한다. 색·미세 대비·흐림을 적용한 뒤에도 이 보호를 사용한다. 따라서 표는 **알고리즘 입력 설정**이며 각 사진에서 실현된 평균 휘도·대비 변화량은 아니다. 구현은 [이미지 변환](../../../src/mediflow_datasets/domain_adaptation_experiment.py)과 [추가 변환](../../../src/mediflow_datasets/camera_extended.py)이 기준이다.

## 4. 3차 MMD·CORAL 실제 학습 계수

MMD는 Source와 Target의 특징 전체 분포 차이를, CORAL은 특징 사이의 공분산 차이를 줄이는 손실이다. 모델이 추출한 수치 특징을 사용하며, 사진 픽셀을 직접 같은 색으로 만드는 연산은 아니다.

```text
전체 학습 손실 = Source 분류 손실 + λMMD × MMD² + λCORAL × CORAL
```

| 분야 | λ MMD | λ CORAL | 특징 차원 | Source 기준 표본 | 상태 |
| --- | --- | --- | --- | --- | --- |
| 현미경 피부 | 0.009276486496767843 | 0.00921319341745932 | 1280 | 80 | 완료 |
| 웹캠 얼굴 | 0.01068621196402111 | 0.044213753365170944 | 512 | 40 | 완료 |
| 현미경 두피 | 0.10659643952049762 | 0.16272447754974867 | 1280 | 40 | 완료 |
| 휴대폰 얼굴 | 실행 시 계산 | 실행 시 계산 | 출발 모델 결정 후 | 40 | 학습 전 |

이 계수는 출발 모델에서 측정한 값으로 다음과 같이 한 번 계산해 고정했다.

```text
C = max(0.05, 초기 Source Train 분류 손실)
λMMD   = min(10, 0.05 × C / 초기 MMD²)
λCORAL = min(10, 0.05 × C / 초기 CORAL)
```

초기 기준 C는 피부·얼굴 **0.05**, 두피 **0.5730785131454468**이다. 초기 각 정렬 항을 C의 5% 수준으로 맞춘다는 뜻이지, 매 epoch에서 최종 손실의 5%를 차지한다는 뜻은 아니다. RBF 커널의 제곱 대역폭 배수는 `[0.25, 1, 4]`다. 원본 대역폭·초기 손실·기준 특징의 정확한 값은 JSON의 `alignment`에 기록했다.

기존 세 분야는 각각 **epoch당 정렬 배치 10개, Target 사용 40장, 5 epoch 전체 정렬 갱신 50회·Target 사용 200회**가 이력에서 확인되었다. 중복 사용을 포함한 횟수이며 독립 사진 200장을 뜻하지 않는다. 4명에서 정렬 배치마다 사람당 1장씩 뽑았다. 전체 Source 분류 학습 배치에는 모두 분류 손실이 들어가고 그중 일부에만 정렬 손실이 추가된다.

PMG 얼굴은 한 Source 배치에서 부분 분류 3회와 결합 분류 1회, 총 4회 가중치를 갱신한다. 정렬 손실은 이 중 결합 분류 갱신에만 추가된다. 단일 EfficientNet은 배치당 1회다. Target에는 질환 정답이나 임의의 가짜 라벨을 붙이지 않았다.

휴대폰의 MMD·CORAL 계수는 **아직 미계산**이다. 실제 Colab에서 선택한 출발 모델과 휴대폰 42장으로 새로 계산하며, 웹캠의 계수를 복사하지 않는다. 별도 참여자 10장은 이 계산과 학습에서 제외한다.

## 5. 학습량·출발 모델·분할

모든 완료 실행과 현재 휴대폰 계획의 공통값은 다음과 같다.

| 항목 | 값 |
| --- | --- |
| 모델당 적응 학습 | 5 epoch |
| Optimizer / 학습률 | Adam / 0.00001 |
| 난수 seed | 42 |
| 변환 적용 확률 | 0.5 · 전체 변환 묶음을 적용할지 이미지별 결정 |
| 범위 안 파라미터 선택 | 균등 분포, 양 끝이 같으면 고정 |
| 기울기 global norm 상한 | 1.0 |
| 업데이트 대상 | backbone 마지막 30개 층 위치 중 BatchNormalization을 제외한 층 + 분류층 |
| BatchNormalization | 동결 |
| 입력 | RGB float32 0–255 · 모델 외부 /255 추가 없음 |
| Label Smoothing | 두피 선정 B1만 0.05, 나머지 0 |

이미지마다 각 변환을 따로 50% 확률로 켜는 설정이 아니다. **전체 변환 묶음 적용 확률이 50%**이며 적용할 때 범위 안 값을 뽑는다. 고정된 seed와 사진 경로·epoch를 사용해 재현한다. 최초 밝기만 적용하자는 계획과 달리, 실제 완료 1차는 피부의 대비와 얼굴의 대비·좌우 조명도 포함한다. 두피 1차는 실제로 밝기만 비항등이다.

## 7. Test에 어떤 값으로 적용했는가

원본 Test 파일은 수정하지 않았다. 메모리에서 원본과 변환 조건을 따로 평가했다. 이전 Test는 `clean / lighting / expanded`, 추가한 4차 Test는 이 세 조건에 `stage4_lighting / stage4_expanded`를 더했다. 변환 seed는 **1707**이다. 변환 Test는 원본을 보존한 별도의 촬영 변화 평가이며 실제 장비 질환 정답 사진의 평가가 아니다.

평가의 `lighting`과 `expanded`는 해당 사진 변환 조건을 적용하는 고정 평가이지, 학습의 변환 확률 0.5로 원본 절반을 섞는 절차가 아니다. `expanded`와 `aligned`는 사진 변환이 같으므로 3차 전용 사진 변환 조건은 따로 필요하지 않다.

실제로 확인한 Source Test 비교는 **기본~3차의 36개 결과 재사용 + 4차 신규 15개 = 51개**다. 5모델×5조건×3분야 전체 75개를 새로 평가한 것은 아니다. 새 4차 변환 두 조건은 이전 모델의 점수가 없으므로 그 조건에서 모든 차수 간 비교가 완성된 것으로 쓰면 안 된다. 원본 Test 결과와 해석은 [최신 결과 분석](ADAPTATION_STAGE4_TEST_RESULT_REVIEW_20261111.md)을 따른다.

학습 epoch와 후속 후보는 Validation 기준이다. Test를 반복해서 강도 최적화에 쓰면 안 된다. 과거 저장 모델이 동일 Test에 노출되었을 가능성, Source의 사람·병변·세션 식별 누락은 별도 한계로 남아 있으며 완전한 독립성이나 누수 배제를 주장하지 않는다.

## 8. 보고서에 바로 쓸 수 있는 설명

> 공개 데이터와 실촬영 데이터의 분포 차이를 바탕으로 분야별 촬영 변환 범위를 설정했다. 1차는 밝기·대비·좌우 조명을, 2차는 같은 조명에 Lab 색 이동·미세 대비·가우시안 흐림을 추가했다. 3차는 2차와 동일한 사진 변환에 MMD 및 CORAL 손실을 함께 추가했다. 4차는 재측정 결과에 따라 세 분야의 변환 묶음을 각각 다시 정했다. 각 모델을 기존 저장본에서 독립적으로 5 epoch 적응 학습했으며, Adam 학습률 0.00001, 변환 적용 확률 0.5, seed 42를 고정했다. 변환 설정과 손실 계수의 실제 수치는 본 조절값 표 및 원본 실행 기록에 보존했다.

실제 촬영 사진은 질환 정답이 없는 환경 조사 자료다. **실제 환자 분류 정확도가 향상되었다고 결론 내릴 수 없다.** 특징 분포 차이나 예측 확신도 감소·증가만으로 정확도 개선을 대신하지 않는다. 배경·부위·사람·질환과 장비 차이를 완전히 분리한 측정도 아니다. 촬영 인원과 기기가 적으므로 일반적인 장비 분포라고 가정하지 않는다. 추가 잡음·JPEG 압축·기하 확대 등을 이번 실험에서 적용했다고 쓰지 않는다.
