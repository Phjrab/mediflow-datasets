# 스마트폰 얼굴 적응 · 고정 최종 Source Test 계획

기존 스마트폰 5회와 공동 근접 후보 1회, 총 6회 학습의 결과 회수를 완료했다.
2026-11-12 사용자가 Test 진행을 요청해, 완료 모델·분할·사진 변환을 고정한 평가 코드를 준비했다.
**현재는 실행 준비·로컬 기능 검사 단계이며 실제 Source Test 400장 평가 결과는 아직 없다.**

Test에서 새 모델·강도·epoch를 선정하거나 재학습하지 않는다. 기존 공식 후보·패키지는 유지한다.

## 고정 모델과 비교 조건

원본 PMG·EfficientNet-B0·256, 1차 선정 PMG, 2차, 3차, 4차, 추가 5차를 비교한다.
초기 B0·224는 이전 1차 비교에서 선택되지 않았으므로 이번 과정 비교에는 포함하지 않는다.
6개 모델 모두 같은 입력 크기·출력 처리·클래스 계약을 유지한다.

| 조건 | 적용 내용 | 설정 근거 |
| --- | --- | --- |
| clean | 변환 없는 원본 Test | 동일 기존 원본 |
| phone_lighting | 1차 조명 묶음 | 완료 1차 설정 그대로 |
| phone_expanded | 조명·색·약한 미세 대비/흐림 | 완료 2·3차 설정 그대로 |
| phone_refit | 기존 4차 조명·강한 질감/흐림 | 완료 4차 설정 그대로 |
| phone_joint | 새 조명·작은 Lab a/b 이동, 추가 질감·흐림 없음 | 완료 추가 5차 설정 그대로 |

여섯 모델에 다섯 조건을 교차 적용해 30개 비교를 측정한다. Test를 모델마다 다르게 만들지 않는다.
변환 범위는 [이전 1~4차 결과](SMARTPHONE_ADAPTATION_RESULT_REVIEW_20261112.md),
[추가 5차 결과](SMARTPHONE_JOINT_RESULT_REVIEW_20261112.md)의 실제 적용값에서 복사했다.
새로 조절한 변환은 없다. 고정 계획 JSON에 전체 수치를 원래 자릿수로 남겼다.
다섯 조건 중 `phone_refit`은 강한 변화에 대한 평가이며 모든 스마트폰에서 가장 가까운 조건이라는 뜻은 아니다.

고정 조건은 원본 Test 400장, 건선·아토피·여드름·정상·주사 순서, 중앙 정사각형 256px,
RGB float32 0–255, PMG 네 출력 logit 합산 후 softmax, batch 8, 이미지 경로별 seed 1707이다.
저장 모델 내부 Rescaling을 유지하며 외부 `/255`를 추가하지 않는다.
학습에서 변환 확률 0.5였던 것과 달리 평가 시에는 원본 조건과 각 변환 조건을 분리해 100% 적용한다.
이는 적용 빈도 차이이며 변환 수치 범위를 더 강하게 만든 것이 아니다.

변경하는 것은 **평가에 사용하는 데이터 분할을 Validation에서 기존 Test로 바꾸는 것**이다.
필요한 동반 변경은 원본 Test 입력 캐시·모델별 예측 저장·지표 및 비교 그래프 생성이며,
공통 입력·고정 선정·재실행 가능성을 보장하기 위한 것이다. 모델 학습·사진 변환 범위는 고정한다.

## 실행 효율과 결과물

이미지를 Colab 로컬 SSD에 한 번 준비하고 모든 모델에 같은 배열을 전달한다.
모델을 하나씩 로드해 여섯 모델을 동시에 GPU 메모리에 올리지 않는다. 모델·조건·배치 진행률을 표시한다.
조건별 점수/지표를 저장하고 재실행 시 해시·실행 계획·재계산 지표가 같은 완료 조건을 재사용한다.
입력 캐시가 손상되거나 설정·기존 모델이 달라지면 중단한다. 기존 학습 폴더를 출력으로 지정하는 것도 거부한다.

생성할 결과는 Accuracy·Macro-F1 비교 JSON/CSV, 클래스별 Precision·Recall·F1과 Confusion Matrix,
개별 Test 이미지의 정답·예측·5개 점수, 비교 그래프 1개와 모델별 혼동행렬 그림 6개,
고정 계획·분할·실행 코드·환경 버전이다. 결과 ZIP에는 모델·원본 사진·키가 들어가지 않는다.
새 학습이 없어 학습곡선은 만들지 않는다.

Drive 출력은 `MediFlow_smartphone_runs/test_ad2338eaa932`이고 결과 ZIP은
`MediFlow_Smartphone_Final_Test_Results_20261112.zip`이다.
Colab 완료 후 이 ZIP을 받아 결과를 검증·정리한다. 실행 전에는 수치를 만들어 보고하지 않는다.

## 해석 한계

이 평가는 기존 공개 데이터에 휴대폰 관찰을 참고한 가상 변환을 적용한 Source Test다.
실제 휴대폰 질환 사진에 대한 정답 기반 평가는 별도 확보가 필요하다. 사람·병변·세션 식별 누락으로
완전한 누수 배제를 주장하지 않으며 과거 저장 모델의 Test 노출 가능성도 미확인이다.
Test 결과를 근거로 이번 변환 강도를 반복 조절하지 않는다. 추후 설정 변경은 별도 가설과 Validation 설계를 둔다.
