## 검토 결과와 학습 가설

후보 `f10926b662a4a43c`는 8개 영상 지표 중 7개를 원본보다 가깝게 했다.
조명 불균일성·시드·사람별 기준을 모두 통과한 후보는 아니며 검토 자료의 `accepted=false`를 그대로 유지한다.
이번 승인은 이를 장비 동등성 통과로 바꾸는 것이 아니라 **해당 후보의 학습 효과를 추가로 비교하는 탐색 실험 승인**이다.
사전 가설은 추가 흐림 없이 함께 조절한 조명·작은 색 이동이 분류 정보를 유지하면서 촬영 변화에 대응하는가이다.

| --- | --- |
| 밝기 제안값 | −19.624129908304198 ~ −10.181201425385177 |
| 대비 배율 | 1.0 ~ 1.1808786167229048 |

| Lab a 이동 | 0.0 ~ 1.0117187500000009 |

밝기·좌우 조명은 RGB 가산 제안값이며 퍼센트가 아니다. 기존 RGB 경계 보호 계산을 그대로 사용한다.
Lab 색 좌표는 RGB 값과 단위가 다르며, 모델은 내부 Rescaling을 포함한 float32 RGB 0–255 입력을 받는다.
외부 `/255`는 추가하지 않는다. 실제 휴대폰 입력의 EXIF·ICC→sRGB·중앙 자르기는 기존 계약을 유지한다.

## 고정 조건과 동반 변경

출발은 **휴대폰 적응 전 선정 PMG·EfficientNet-B0·256**이다.
`results/web_skin/selected_models/v2/web_skin_model.keras`, SHA-256
`83e659dd09a9355135ee0de0197037e81ece962777f59dedae8d9a37b49a3fc4`를 사용한다.
기존 4차 가중치를 이어서 학습하거나 초기 B0 실험을 다시 수행하지 않는다.

Train 3535 / Validation 499 / Test 400, 클래스 순서 건선·아토피·여드름·정상·주사,
seed 42, Adam 0.00001, batch 8, Label Smoothing 0, 변환 확률 0.5, 5 epoch,
backbone 마지막 30개 층 위치 중 BatchNormalization 제외 미세조정, 기울기 norm 상한 1을 고정한다.
PMG는 배치마다 부분 분류 3회와 결합 분류 1회로 가중치를 갱신한다.

바꾸는 변수는 **사진 변환 묶음**이다. 색·밝기 등 여러 수치가 함께 바뀌므로 개별 변환 하나의 효과를 분리하지 않는다.
동반 변경은 새 후보 평가용 `phone_joint` Validation 조건 추가와, 기존 20개 비교에 새 결과 10개를 붙이는 것이다.
새 변환에서 이전 모델도 비교하기 위해 필요하며 Source Test나 P05로 강도를 고르지 않는다.

최적 epoch는 원본·새 변환 Validation의 낮은 Macro-F1, 원본 Macro-F1, 앞 epoch로 선정한다.
공통 6모델×5조건 비교의 후보는 각 모델의 다섯 조건 중 최저 Macro-F1, 원본 Macro-F1, 앞 모델 순서다.
공식 후보·패키지를 자동 변경하지 않는다. 기존 source Validation 노출 가능성이 있는 탐색 비교라는 한계도 유지한다.

## 비교·진단·파일 보존

원본·기존 1차 조명·기존 2차 확장·기존 4차 강한 변환·새 공동 후보, 총 다섯 조건을 고정한다.
적응 전과 기존 1~4차의 이전 네 조건 20개 수치는 바이트를 대조한 기존 JSON에서 그대로 재사용한다.
이전 다섯 모델에 새 조건을 적용한 5개, 새 5차 모델에 다섯 조건을 적용한 5개를 추가 평가한다.
전달할 결과에는 새 모델 1개만 넣고 이전 모델을 중복 복사하지 않는다.

새 학습 후 설정용 Target 42장의 특징·예측만 진단한다. 이전 Stage3의 고정 특징 기준과
Source Train 클래스당 8장·총 40장을 사용하며, 이 수치로 모델을 선정하지 않는다.
이미 확인한 P05는 이번 실행·노트북 런타임에서 제외하고 새 독립 평가라고 표현하지 않는다.
실제 질환 정답이 없으므로 Target Accuracy는 만들지 않는다. Source Test의 파일·분할도 유지한다.

기존 공통 ZIP에서 필요한 파일을 읽고 노트북 안의 새 코드·설정만 합쳐 별도 Colab 임시 폴더를 만든다.
원래 ZIP·Drive 1~4차 결과는 읽기만 한다. 입력·모델·코드·고정 분할을 해시로 확인한다.
새 epoch마다 상태를 저장하고 중단 시 이어서 실행한다. 입력은 Colab 로컬 SSD에 캐시하며 사용자 PC 저장소가 아니다.
동일 세션의 원본 Source ZIP·입력 캐시가 일치하면 재사용한다.

학습 진행률·손실·최적 epoch·원본/변환 Validation, 학습곡선·비교 그래프·혼동행렬·특징 거리·예측 변화와
환경 버전·seed·코드·분할·모델 해시를 결과에 남긴다. source의 사람·병변·세션 식별 누락과
과거 저장 모델의 Validation/Test 노출 여부는 여전히 미확인이다. 완전한 누수 배제·장비 동등성을 주장하지 않는다.
