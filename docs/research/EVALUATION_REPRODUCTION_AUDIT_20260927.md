## 재실행 방법과 원본 근거

```powershell
python -m mediflow_datasets.reproduction_audit --repository-root . --output results/EVALUATION_RECORD_AUDIT_NEW.json
```

이번 기계 판독용 결과는 `results/EVALUATION_RECORD_AUDIT_20260927.json`이다. 같은 명령을
새 출력명으로 실행하면 기존 파일을 덮어쓰지 않는다. 이 JSON에는 초기 여섯 모델·현재 세
후보의 모델 SHA-256, 클래스 순서, 보고서와 예측 파일 해시, 재계산 지표 및 확인 범위를 기록했다.

추후 당시 Test 원본이 발견되면 `mediflow-evaluate`로 초기 모델 여섯 개를 다시 평가하고
이 문서의 과거 보고값과 비교할 수 있다. 그 전에는 초기 여섯 모델의 Test 성능을
`재현 완료`로 표시하지 않는다.
