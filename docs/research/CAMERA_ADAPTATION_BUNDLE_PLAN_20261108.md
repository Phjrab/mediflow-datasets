# MediFlow 분야별 카메라 변화 묶음 적용 계획

2026-11-08 · 추가 학습 준비

밝기만 먼저 학습하는 계획을 바꾼다. **한 분야에서 확인한 여러 촬영 변화를 한 묶음으로 적용해 한 번의 비교 실험으로 검증한다.** 세 분야는 각자의 기존 데이터·모델·클래스 계약을 사용한다. 가설은 *실제 촬영을 참고해 구성한 변화 묶음을 학습에 넣으면, 그 변화가 적용된 평가 사진의 분류 성능이 개선되고 원본 성능도 유지되는가*이다. 실험 결과로 확인하는 것은 묶음 전체의 효과다. [촬영 사진과 데이터셋 예시 비교](CAMERA_DATASET_EXAMPLE_COMPARISON_20261108.md).

| 분야 | 한 번에 적용할 변환 초안 | 근거와 확인할 점 |
|---|---|---|
| 웹캠 얼굴 `web_skin` | 화면 안에서 얼굴이 작아지는 효과, 16:9 원본을 정사각형으로 줄일 때의 가로 압축, 전체 밝기와 한쪽이 더 밝아지는 조명 | 사진에서 얼굴 크기·화면 비율·양쪽 볼 밝기 차이를 확인했다. 미리보기의 넓어진 배경은 단순 색으로 근사한다. 실제 천장·선반 같은 배경은 재현하지 못하며, 확대·축소 경계가 특징으로 학습되지 않도록 Train 표본에서 확인해야 한다. 최종 장비의 구도를 바꾸기로 하면 그 구도에 맞춰 축소 범위를 다시 잡는다. |
| 현미경 피부 `skin` | 약한 색감 변화와 약한 흐림 | 실제 팔 사진의 노란 기와 일부 초점 차이를 참고했다. 공개 사진과 실제 사진의 내용도 달랐으므로 색 설정은 장비 보정값으로 보지 않는다. 병변 경계나 색이 흐려지는 범위는 제외한다. |
| 현미경 두피 `hair` | 약한 흐림과 국소적으로 밝아지는 조명 | 실제 프레임에서 초점과 밝은 영역 차이를 확인했다. 인위적으로 모발을 그리거나 가림을 더하면 탈모 등 분류 단서가 달라질 수 있으므로, 모발 가림은 가르마와 초점을 맞추는 촬영 방법으로 다룬다. |

변환 초안은 [카메라 변화 묶음 코드](../../src/mediflow_datasets/camera_augmentation.py)에 있다. 기존 모델의 크기 변환을 먼저 적용하고, 픽셀은 RGB `float32` 0–255를 유지한다. 같은 난수값을 주면 같은 결과와 적용 값을 얻는다. 예시 20장에 적용해 원본과 비교했고, 입출력 크기·픽셀 범위·같은 난수값에서의 재현성을 검사했다. 이 예시는 분할 소속이 확인되지 않아 화면 검토에만 사용했다. 수치 범위는 초안이며, 원래 데이터의 Train에서 표면·질환 특징과 부자연스러운 경계를 확인한 뒤 고정한다.

## 비교 방식

| 비교군 | 실행 |
|---|---|
| A · 기존 모델 | 저장된 기존 후보를 그대로 평가한다. |
| B · 추가 학습 | A에서 시작해 기존 학습 사진으로 추가 학습한다. |
| C · 묶음 적용 | B와 같은 모델·분할·설정으로 추가 학습하고, Train 입력 일부에 해당 분야의 변화 묶음을 함께 적용한다. |

B와 C의 시작 저장본, 클래스와 순서, 사진 선택 순서·학습 횟수, 입력 처리, 학습률·배치·손실 함수·조정 층·난수값을 고정한다. 바꾸는 조건은 **촬영 변화 묶음의 적용 여부** 하나다. 기존 증강이 있다면 두 비교군에 공통으로 유지한다. 설정·적용 강도와 비율, 이미지의 원본 ID와 난수값, 버전·코드·환경·체크포인트를 기록한다. 일반 참여자 사진은 변환의 근거를 정하는 관찰 자료로 사용한다.

원본 Validation과 묶음을 적용한 Validation 복사본에서 동일한 사진과 정답으로 A·B·C를 비교한다. 변환 범위와 채택 기준을 고정한 후 **원본 Test와 묶음 적용 Test 복사본**에서 최종 평가한다. 모든 모델에 같은 변환 평가 사진을 제공하고, 원본 Test와 복사본 결과를 나눠 기록한다. 원본 성능 유지 여부와 변화가 적용된 사진의 Macro F1·클래스별 재현율을 함께 확인한다. 이 평가로 말할 수 있는 성능은 모의 촬영 변화가 적용된 공개 데이터의 범위다.

## 데이터 확인과 실행 순서

Google Drive 프로젝트의 [datasets 폴더](https://drive.google.com/drive/folders/1BUbZbCLmQ_IeRo5WIsHZXo7hDFMxqrSC)에서 다음 후보 압축 파일의 이름과 크기를 확인했다. 원래 파일의 해시 일치와 분할 목록은 아직 검증하지 않았다.

- Web Skin PMG v2 · [web_skin_datasets](https://drive.google.com/file/d/1e7Zuj8b7CWmV8XoDMmnNQY_OKzvRJrnC/view).
- Skin v1 · [skin_datasets](https://drive.google.com/file/d/1fCivi2l1hE13S4RMyiFVXu0v88FT_dCL/view).
- Hair 5클래스 v2 · [hair_datasets](https://drive.google.com/file/d/1Se80pBLPsLKI7jhMrVjIeC5-_obolgHt/view). Hair 6클래스는 [별도 데이터](https://drive.google.com/file/d/1aoC8LP5jGqWc9Y4f0LJoLbOMWmCX4_X6/view)를 명시적으로 선택할 때 따로 비교한다.

Colab에서 기존 후보가 사용한 데이터 해시, 클래스 순서, Train·Validation·Test 목록을 대조하고 분할 간 사람·병변·촬영 세션·동일/유사 사진·증강 출처 겹침을 점검한다. 확인할 수 없는 항목은 기록한다. Train 표본에서 변환이 특징을 가리는지 확인하고 변환을 고정한 뒤, 분야별 묶음으로 추가 학습과 평가를 진행한다. 현재 완료한 범위는 변환 코드와 예시 미리보기이며, Colab 학습과 성능 평가는 진행 전이다.
