## 아직 확인하지 못한 내용

1. 사용자가 확인한 여섯 증상값 모두 `0`인 조건은 ZIP에 대응 라벨 JSON이 없어 파일별로 독립 검증하지 못했다. 현재는 **사용자 확인 라벨**로 기록한다.
2. Drive의 기존 `hair_datasets` ZIP과 새 534장 사이의 파일·픽셀·사람 ID 겹침은 아직 비교하지 못했다. 이것을 확인하기 전에는 Train/Validation/Test를 확정하지 않는다.
3. `534`장은 서로 다른 JPG 수이고, 서로 다른 사람은 파일명 기준 `105`명이다. 사진만 80:10:10으로 무작위 분할하면 같은 사람이 여러 분할에 들어갈 수 있다. 사람 ID를 묶어 분할하고 실제 클래스별 사진·사람 수를 보고해야 한다.
