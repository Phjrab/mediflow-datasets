# 2차 확장 적응 학습

2차는 1차 검증에서 선택된 **피부 기본, 얼굴 선정, 두피 선정**의 학습 전 저장본으로 시작한다.
기존 공통 ZIP v3의 모델 해시를 1차 선택·완료 기록과 대조한다. 1차 학습 후 모델은 같은
검증 사진에서 비교 점수를 재는 데 사용한다.

| 분야 | 출발 모델 | 1차 조명 변환에 추가하는 범위 |
|---|---|---|
| 피부 | 초기 EfficientNet-B0 · 224 | 약한 Lab 색 이동, 미세 대비 감소·증가, 약한 흐림 |
| 얼굴 | v2 PMG · B0 · 256 | 약한 Lab 색 이동, 미세 대비 감소, 약한 흐림 |
| 두피 | 5클래스 v2 EfficientNet-B1 · 384 | 약한 Lab 색 이동, 미세 대비 감소, 약한 흐림 |

시험 촬영 4명의 조명 조건 간 차이에서 보수적으로 정한 범위를 재사용한다. 상세 범위는
공통 ZIP의 `references/<분야>.json`과 각 결과의 `run_configuration.json`에 있다.
흐림은 같은 사람·조명 조건 안에서 측정한 선명도 차이를 근사한다. 피부는 입력 좌표에서
최대 표준편차 0.525px, 얼굴 0.3875px, 두피 1.06875px를 적용한다. 색과 질감 차이에는
촬영 환경 외에 촬영 부위·내용 차이도 섞일 수 있으므로 촬영 변화를 모사한 파일럿으로 해석한다.

1차와 같은 데이터 ZIP, 클래스 순서, 분할, 입력 정책, 배치 크기, 시드 42, 학습률 0.00001,
모델당 5 epoch를 사용한다. 같은 사진에 같은 50% 확률로 변환을 적용하고, 2차에서는
변환에 색·미세 대비·흐림을 묶어서 추가한다. 분야별로 한 번씩 총 세 번 학습한다.
데이터를 다시 점검한 뒤 원본 Train/Validation/Test 목록이 1차와 일치하는지 확인한다.

원본·조명·확장 Validation은 같은 원본 사진과 정답으로 구성한다. 변환에 쓰는 시드는
사진별로 고정한다. 2차 모델은 원본과 확장 검증 Macro-F1 중 낮은 점수가 가장 높은 회차를
고르고, 동점이면 원본 검증 점수가 높은 회차를 고른다. 공통 검증표는 학습 전·1차·2차 모델의
Macro-F1과 Accuracy를 제공한다. 회차별 기록에는 혼동행렬과 클래스별 Recall도 들어간다.
Test 평가는 후속 단계이며 검증 점수는 기존 학습 자료 노출 가능성이 있는 탐색 결과다.

1. Colab에서 [2차 노트북](../../notebooks/camera_adaptation/MediFlow_Adaptation_Stage2_Expanded_20261110.ipynb)을 열어 GPU를 선택하고 **모두 실행**한다.
2. 기존 `내 드라이브/mediflow_Project/MediFlow_Adaptation_Common_v3.zip`과 1차 결과를 읽는다.
   노트북에 포함된 2차 코드를 Colab의 임시 작업 폴더에 적용한다.
3. `내 드라이브/MediFlow_adaptation_runs/4ae6e07eb4af1225/stage2`의 `validation_comparison.csv`,
   분야별 `complete.json`, `expanded/history.json`, `best.keras`에서 결과를 확인한다.
   같은 노트북을 다시 실행하면 완료 분야를 재사용하고 미완료 분야는 저장된 epoch에서 복원한다.

3차는 같은 저장본에서 2차의 변환 조건을 유지하고, 특징 분포를 정렬하는 학습 손실을 추가하는 계획이다.
