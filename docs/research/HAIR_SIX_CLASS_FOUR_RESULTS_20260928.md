# Hair 6클래스 원본·증강 × B0·B1 실험 결과

상태: **Colab 네 실험·선정 후보 Test·두 모델 패키징 완료**. 성능 우선 B1·384·원본과 경량 비교 후보 B0·256·증강의 최신 해석은 [5클래스와 6클래스 종합 분석](HAIR_5CLASS_6CLASS_EXPERIMENT_ANALYSIS_20260928.md)에 기록했다.
분석 근거: `results/hair/archives/hair_six_class_four_20260928_011824_ad21e8ae_reports.zip`의
원본 JSON·CSV 및 Drive 결과 폴더
[`hair_six_class_four_20260928_011824_ad21e8ae`](https://drive.google.com/drive/folders/10ZtTa_LpLtX_T2r4eY5-csKig2c5ybzN).
보고서 ZIP은 모델 가중치를 포함하지 않는다.

## 데이터와 실험 조건

- 6클래스: 모낭사이홍반, 미세각질, 비듬, 탈모, 피지과다, 양호.
- 기존 Hair 원본 12,536장과 양호 원본 534장을 사용했다. Train 원본은 10,460장,
  Validation 원본은 1,305장, Test 원본은 1,305장이다. 양호 원본은
  Train 428장, Validation 53장, Test 53장으로 사람 ID별 분할됐다.
- 증강 조건의 추가 Train 이미지는 7,155장이고, 그중 양호는 2,140장이다.
  `hair_clean_v2_6class_d6ac77b7d507.zip`은 Drive `datasets`에 별도 보관됐다.
- 같은 모델 내 원본·증강 비교는 분할·모델·입력 크기·Loss·epoch·seed를 유지하고
  Train 이미지와 그 수량에 따라 계산한 클래스 가중치를 바꿨다. B0와 B1은 구조뿐
  아니라 해상도와 Loss도 다르므로 순수 구조 효과로 해석하지 않는다.
- ImageNet 사전학습에서 새 6클래스 출력층을 학습했다. Head-only 15 epoch 뒤
  후반 30개 층을 미세조정 15 epoch 했다. 각 실험의 체크포인트는 Validation
  Accuracy 기준이며, 네 실험의 최종 선택은 Validation Macro F1 우선이다.

## 해석 범위와 후속 작업

기존 Hair 5클래스의 Test 수치와 이번 6클래스 Test 수치는 문제가 달라 직접적인
성능 향상·하락률로 비교하지 않는다. 기존 5클래스 사진의 사람·촬영 세션 ID는
복구되지 않았고, 새 양호 534장의 원본 JSON도 ZIP에 없어 사람 간 겹침과 라벨을
완전히 독립 검증하지 못했다. 양호 Test가 53장인 점도 지표 해석에 포함한다.

선정된 B1·384·원본 모델과 경량 비교 후보 B0·256·증강 모델의 파일 해시,
6클래스 순서, 입력 규칙을 확인해 각각 패키지로 정리했다. 두 후보의 같은 Test 비교는
[성능 우선·경량 후보 기록](HAIR_SIX_CLASS_LIGHT_HEAVY_COMPARISON_20260928.md)을 따른다.
실제 장비 성능이나 실행 속도는 아직 측정하지 않았으므로 현재 결과를 그 근거로 쓰지 않는다.
