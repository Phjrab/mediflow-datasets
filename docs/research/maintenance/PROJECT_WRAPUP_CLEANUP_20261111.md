# 1~4차·Test 완료 후 프로젝트 정리 · 2026-11-11

촬영·분포 분석·분할 점검·1~4차 학습·Source Test를 [현재 작업 요약](../../PROJECT_SUMMARY_20261111.md)으로 묶었다. 이번 작업은 프로젝트 내부의 자료·안내·임시파일 정리다. 새 학습이나 모델 선정 변경, Drive·Downloads의 파일 정리는 수행하지 않았다.

## 정리한 내용

- 완료한 4차 Test 노트북을 `notebooks/camera_adaptation/completed`로 옮겨 완료한 학습·Test 노트북 7개를 모았다. 이동 전후 노트북 내용은 같다.
- `notebooks/camera_adaptation/archive`에는 미실행 재설정 4차·9개 통합 중단 기록 2개를 유지했다. 중단·준비만 한 코드를 완료한 15개 적응 실험에 포함하지 않았다.
- `configs/README.md`, `output/README.md`를 추가해 설정의 역할과 실제 사용한 분석 노트북 3개의 위치를 안내했다. 고정 JSON·분석 ZIP의 경로와 바이트는 유지했다.
- 프로젝트·문서·노트북 시작점과 최신 보고서에서 과거 실행 지시를 완료·재현 안내로 바꿨다. 로드맵의 촬영 조사 완료와 정답 확인 실제 장비 검증 미완료도 구분했다.
- 기존 결과 폴더·원본 사진·모델·원본 JSON/CSV·학습 당시 코드 사본·보고서 그림은 기존 위치에 보존했다. `.git`과 `.venv`도 유지했다.

## 임시 자료 처리

정리 전 `.tmp`와 `.ruff_cache`의 대상 100곳에는 총 3,172개 파일, 778,157,771 bytes가 있었다. 다음과 같이 처리했다.

| 처리 | 기존 파일 경로 수 | 근거 |
| --- | ---: | --- |
| 생성 가능한 검사 산출물·캐시 제거 | 2400 | 테스트용 모형·가짜 자료, 미사용 패키지 복사본, 글꼴·바이트코드·Ruff 캐시 |
| 기존 자료와 같은 임시 복사본 제거 | 362 | 현재 원본과 SHA-256 일치, manifest에 원본 경로 기록 |
| 고유한 과거 보조 자료 압축 보존 | 410 | 중복 내용은 하나로 묶어 고유 파일 363개 보관, 경로·해시 대응표 유지 |

고유 보조 자료 보관 ZIP은 173,864,703 bytes다. 임시 대상 제거량에서 이 보관 크기를 빼면 **파일 크기 기준 순 604,293,068 bytes 감소**다. 이는 실제 파일시스템의 여유 공간을 별도로 측정한 값이 아니며 OneDrive 저장 방식에 따라 디스크 사용량과 다를 수 있다.

보관본에는 과거 암호화 촬영 캐시·발표 원본·보조 코드·검토 이미지 등이 있어 로컬 전용 이력에 둔다. 현재 모델이나 공식 결과를 이 ZIP으로 대체하지 않는다. [정리 manifest·보관 자료 안내](../../../camera_capture/_review/history/project_wrapup_20261111/README.md)에 대응 관계가 있다.

`.tmp/final-test-report-libraries`는 현재 로컬 그래프 도구가 참조하는 선택 라이브러리여서 유지했다. `.tmp/strength-native-temp`는 모델 검사 때 쓰는 경로여서 유지했다. [임시 경로 안내](../../../.tmp/README.md)를 추가했다.

## 보존과 재현 확인

정리 전에 원본 이미지·모델·결과·설정·노트북·Word·발표 자료·실행 코드 등 보호 대상 4,610개 파일의 SHA-256을 기록했다. Markdown 안내와 경로를 수정할 로컬 검사 스크립트 2개는 원본 수치 자료와 구분했다. 이동한 노트북 한 개는 이전→현재 경로 대응으로 대조한다.

정리 manifest에는 임시 대상별 처리 이유, 중복의 원본 참조, 고유 자료의 ZIP 항목과 해시를 기록했다. 제거 전 보관 ZIP을 다시 열어 모든 보관 항목을 검증했고, 실제 제거는 작업 폴더 안의 절대 경로와 reparse point 여부를 확인한 뒤 PowerShell의 `Remove-Item`으로 실행했다. 새 정리로 기존 원본 모델·결과 수치를 바꾸지 않았다.

코드 검사·자동 검사·원본 해시와 문서 연결의 최종 확인 결과는 [정리 이력](../../../camera_capture/_review/history/project_wrapup_20261111/README.md)의 검증 파일을 따른다.

최종 확인에서 보호 대상 **4,610개 모두 이동 전후 해시가 일치**했다. 이 안의 저장 `.keras` 40개와 실제 촬영 원본 124장도 동일하다. 고유 보조 자료 ZIP의 363개 항목과 이동한 Test 노트북도 원본 바이트와 일치했다. 새 종합 문서의 공통 Test 비교 9행은 검증된 결과 JSON과 대조했다.

Markdown 문서 170개에서 로컬 연결을 확인했고 끊어진 링크는 없었다. `ruff check --no-cache src tests` 통과, 전체 pytest **200개 통과·3개 건너뜀**이다. 건너뛴 3개는 기본 환경에 matplotlib이 없는 기존 그래프 검사다. 검사에서 새로 생성한 작업용 임시폴더도 제거했다. [최종 검증 JSON](../../../camera_capture/_review/history/project_wrapup_20261111/verification.json)에 수치를 기록했다.
