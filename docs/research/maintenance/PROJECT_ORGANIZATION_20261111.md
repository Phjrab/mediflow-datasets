# 전체 문서·실행 이력 대조와 폴더 정리 · 2026-11-11

## 현재 단계

실제 촬영 환경 적응 1·2·3차와 최종 Source Test는 완료했고, 4차 촬영 변환 수정본은 학습 직전이다. 이번 작업은 로컬 자료 정리다. 새 학습·새 정확도 측정·Drive 변경·Git commit/push는 수행하지 않았다.

사용자는 보관만 늘리기보다 프로젝트 진행에 필요 없는 자료를 삭제하고 짧은 기록을 남기도록 요청했다. 실제 학습 입력·실행 결과·당시 코드는 유지하고, 중복과 대체된 준비 자료를 정리했다.

## 검토와 실행 상태 대조

정리 전 `docs`의 Markdown 85개, Word 2개의 문자 내용과 과거 ZIP 안의 Markdown 13개를 읽어 제목·본문의 실행 상태·연결 자료를 목록화했다. Word 파일과 과거 ZIP은 내용·위치를 바꾸지 않았다. 문서를 사용자가 직접 열었는지는 추측하지 않았다.

[전체 문서 대조표](../../DOCUMENT_INDEX.md)와 [실행 코드·결과 대조표](../../../notebooks/EXECUTION_INDEX.md)를 만들었다. 주요 확인 사항은 다음과 같다.

- 카메라 1차는 6개 실험, 2차와 3차는 각 세 분야 완료 기록이 있다. 최종 Source Test는 세 분야·네 모델 상태·세 조건의 36개 비교다.
- 9개 통합 실험은 두피 조명 2회차까지만 확인된 중단 이력이다. 완결 학습 결과로 세지 않았다.
- 별도 두피·피부/얼굴 준비본은 완결 학습 결과가 확인되지 않아 삭제한 준비본으로 기록했다.
- 공개 데이터 노트북 04의 3개 seed 반복 완료 자료는 확인되지 않았다. 노트북 05·07은 기존 안내에서 미실행 구현으로 명시돼 있어 완료 실험과 구분했다. 이 세 코드는 기존 노트북 검사·생성 도구와 연결돼 있어 유지했다.
- MedSigLIP 등 실행했지만 미채택한 실험은 실행 결과다. 미채택이라는 이유로 삭제하지 않았다.
- LLM·VLM·키오스크 자료는 검토·설계와 실제 MediFlow 통합을 구분하고, 카메라 적응 이후 작업으로 표시했다.

## 경로와 코드 수정

문서의 상대 링크를 새 위치에 맞췄다. 이동한 문서에는 작성 시점과 현재 실행 상태를 구분하는 안내를 붙였다. 원본 결과 JSON/CSV와 코드 사본 안의 과거 경로는 당시 기록이므로 수정하지 않았다. 정리 계획의 `moves`로 현재 경로를 찾는다.

움직인 자료를 읽는 기존 생성기·발표 그림 도구의 입력 경로만 수정했다. 현재 4차 생성기, 학습·변환 런타임, 설정, 노트북은 바꾸지 않았다. 원본 수치와 모델을 새 값으로 바꾼 작업이 아니다.

## 확인 결과

보존 대상 4,289개 파일의 SHA-256을 정리 전과 대조해 모두 일치했다. 실제 촬영 원본은 124장이며 Word 2개도 원본과 동일하다. 기존 연구 문서 74개의 표 안 숫자 배열도 변경 전과 일치했다. 실제 모델·입력 배열·결과 JSON/CSV·유지한 노트북과 당시 코드 사본의 내용은 보존됐다.

현재 4차 설정 SHA-256은 `492ee01afb4579b6402fca29459c59d56618243589642fc022db18bbbe45a165`로 유지됐다. 현재 생성기로 메모리에서 재구성한 노트북도 저장본과 일치했다. 이동한 문서를 읽는 경로와 기존 공통 안내 파일도 확인했다.

`ruff check --no-cache src tests`를 통과했고, 전체 pytest는 **191개 통과·3개 건너뜀**으로 끝났다. 건너뛴 3개는 기본 가상환경에 `matplotlib`이 없어 실행하지 않은 기존 그래프 검사다. 코드 오류로 실패한 검사는 없다. 검사에서 생성한 임시파일 1,219개와 비어 있는 폴더 2개도 별도로 정리했다.

안내·보고서의 로컬 링크 검사와 `git diff --check`도 통과했다. 최종 파일·링크 수와 세부 결과는 로컬 `verification.json`에 기록했다.
