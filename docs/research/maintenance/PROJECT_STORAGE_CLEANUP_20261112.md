# 프로젝트 용량·폴더·문서 정리 · 2026-11-12

## 작업 범위

어댑테이션 학습·Source Test·패키징 완료 후, 사용자가 요청한 프로젝트 내부의 불필요한 큰 파일과 안내를 정리했다.
기존에 커밋 전이던 수치 보고서·엑셀·분석 코드도 보존했다. 새 학습·모델 선정 변경·Drive/Downloads 변경은 하지 않았다.
실제 이미지·고유 모델·원본 JSON/CSV·노트북·발표자료와 `.git`·`.venv`는 유지했다.

## 제거·보관한 용량

| 정리 대상 | 처리 |
| --- | --- |
| 과거 분석용 실행 ZIP 2개 | 중복 모델은 기존 원본 참조, 고유 코드·설정은 작은 보관본에 유지. 원래 ZIP과 정확히 같은 바이트로 복원 검증 후 제거. |
| 스마트폰 대체 전 실행 ZIP 1개 | 최신 실행 ZIP과 중복되는 모델·암호화 입력을 참조하고 고유 구성은 압축 보존. 최신 ZIP은 유지. |
| Skin archives의 동일 ZIP 1개 | candidates에 동일 SHA-256 ZIP이 있어 사본만 제거. |
| 임시 폴더·캐시 | 중복 설치된 그림 라이브러리, 완료 검사·생성 작업의 임시 자료 제거. 고유 보조 코드·검사 기록은 압축 보존. |
| 외부 `node_modules` junction 2개 | 링크 자체만 제거. 외부 런타임 폴더에는 삭제 명령을 실행하지 않음. |

원래 파일 크기 합계 **438,470,982 bytes**를 제거했다. 코드·설정·수정 전 안내의 새 로컬 보관본은 현재 **8,944,670 bytes**다.
새 안내·검증 파일의 크기 차이와 작업 종료 시점의 순 정리량은 [최종 검증 JSON](PROJECT_STORAGE_CLEANUP_20261112.json)을 따른다.
파일 크기 합계이며 실제 디스크 여유 공간 증가를 측정한 수치는 아니다. OneDrive·Git 이력의 저장 방식과 구분한다.

[로컬 보관본·복원 안내](../../../camera_capture/_review/history/project_cleanup_20261112/README.md)에
원본 ZIP별 해시·각 항목의 위치·ZIP 메타데이터와 복원 방법을 남겼다.
현재 고정 Python 환경에서 네 ZIP을 임시 경로에 실제 복원하고 전체 SHA-256이 원본과 같은지 확인했다.
복원에는 유지한 모델·최신 ZIP·작은 보관본이 필요하며 기존 파일은 덮어쓰지 않는다.

## 유지한 모델과 자료

완료한 21회 학습의 고유 체크포인트는 과거 비교·재평가 근거이므로 모두 유지했다.
최종 피부 4차·웹캠 4차·두피 2차·스마트폰 4차 패키지, 기존 공개 데이터 선정 모델 7개,
초기 비교 모델·Hair 6클래스 연구 자료·실행 당시 코드·학습곡선·평가 결과·발표자료를 삭제하지 않았다.
`selected_models`, `candidates`, `presentation/models`의 같은 모델은 프로그램·보고서·발표 전달 경로가 있어 유지했다.
현재 프로그램이 읽는 촬영 입력 캐시와 최신 공통 실행 ZIP도 유지했다.

현재 `.venv`에서 matplotlib·NumPy·Pillow가 직접 로드됨을 확인했다.
따라서 같은 라이브러리를 별도 설치했던 `.tmp/final-test-report-libraries`를 제거해도 그림 도구의 기본 실행 환경은 유지된다.
테스트용 임시 자료와 실제 실험 결과를 구분했다. 실제 참여자 사진·복호화 키는 이 공개 문서에 포함하지 않는다.

## 폴더·문서 정리

- 수치 엑셀을 `outputs/<작업 ID>/`에서 `presentation/report_assets/adaptation_numeric_review_20261112/`로 이동했다. 내용과 SHA-256은 같다.
- 비어 있던 `outputs/`를 제거하고 [현재 폴더 안내](../../PROJECT_LAYOUT.md)를 추가했다. `output/`은 분석·실행 준비물 역할로 유지한다.
- 루트 README의 중복된 진행 이력을 줄이고 최신 완료 상태·현재 후보·자료 위치를 먼저 보이게 정리했다.
- [현재 로드맵](../../ROADMAP.md)은 완료 범위·원래 14단계의 상태·남은 과제로 줄였다.
- 종전 날짜별 준비·중단·미실행 기록과 단계별 상세 내용은 [로드맵 이력](ROADMAP_HISTORY_20261112.md)에 보존했다. 옛 수치와 연구 결과를 현재 상태로 덮어쓰지 않았다.
- 문서 시작점·전체 색인·연구/정리 안내·결과/실행 준비 안내에서 스마트폰 Test·패키징 완료 상태와 자료 연결을 맞췄다.
- 날짜가 있는 과거 연구 보고서와 실행 당시 코드 사본은 역사적 기록으로 유지했다. 수치 보고서의 엑셀 링크만 새 위치로 수정했다.

## 검증과 한계

정리 전 원본 자료의 해시 목록, 작업 목록, 문서 제목·상태·링크 검토를 남겼다.
삭제는 저장소 내부의 절대 경로와 reparse point를 확인한 뒤 PowerShell의 `Remove-Item`으로 실행했다.
기존 원본 수치·모델의 보존, 압축 복원, 전체 검사·현재 안내 링크 결과는 최종 검증 JSON을 따른다.

과거 경로 수정 전 사본 등 로컬 이력 안의 Markdown은 당시 경로를 그대로 남겼다.
그 안의 옛 상대 링크를 현재 안내의 끊어진 링크로 세지 않는다. 현재 사용 안내는 별도로 검사한다.

이 작업은 로컬 정리이며 새 커밋·푸시는 하지 않았다. 다음 시스템 작업의 범위와 실제 장비 성능 검증은 [로드맵](../../ROADMAP.md)을 따른다.

최종 검증: 보호 대상 5,003개와 `.keras` 모델 49개가 기존 해시와 일치했다. Word 2개는 크기·수정 시간이 같고, 경로를 수정한 연구 보고서 5개의 표 내용도 같다. 현재 안내 Markdown 196개의 로컬 연결에 누락은 없었다. `ruff check src tests` 통과, 전체 pytest 278개 통과·기존 선택 의존성 pandas 부재로 3개 건너뜀이다. 새 기록을 포함한 파일 크기 기준 순 감소는 약 429MB이며 정확한 값은 최종 검증 JSON에 있다.
