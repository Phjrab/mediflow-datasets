# Web Skin 논문 기반 3개 방법 Validation 결과

## 1. 실험 목적

기존 Web Skin `EfficientNet-B0 · 256 · Cross Entropy` 모델을 기준으로 얼굴 피부 이미지의
분류 성능을 높일 수 있는 논문 기반 학습법을 비교했다. 모델 선택에는 고정 Validation
500장만 사용했으며 Test는 열지 않았다.

비교 방법은 다음 세 가지다.

- **WS-DAN 응용**: 모델의 attention으로 중요한 영역을 확대하고 전체 이미지와 함께 예측
- **PMG 응용**: 여러 크기의 이미지 조각 순서를 섞어 미세한 국소 특징 학습을 강화
- **MixStyle**: 학습 중 특징의 통계량을 섞어 조명·색감·촬영 환경 변화에 대한 일반화를 유도

## 2. 고정 조건과 변경 변수

| 구분 | 내용 |
|---|---|
| 도메인 | `web_skin` |
| 데이터 | `web_skin_datasets.zip` |
| 데이터 SHA-256 | `f8908af3d54e521ad14c37a44b569d33fe92be3b8b9b66a8d80faf4ba964072d` |
| 클래스 순서 | 건선, 아토피, 여드름, 정상, 주사 |
| Train | 증강 학습 데이터 7,200장 |
| Validation | 원본 500장, 클래스별 100장 |
| 입력 크기 | 256×256 |
| Backbone | ImageNet pretrained EfficientNet-B0 |
| 학습 단계 | Head-only 15 epoch + partial fine-tuning 10 epoch |
| Batch size | 32 |
| 모델 선택 지표 | Validation Macro F1 |
| Test 평가 | 수행하지 않음 |
| 변경 변수 | WS-DAN, PMG, MixStyle 학습법 |

기존 기준선은 같은 데이터 SHA-256을 사용한 저장 결과를 재사용했으며 이번 실행에서 다시
학습하지 않았다.

## 3. Validation 결과

| 모델 | Accuracy | Macro F1 | 기준선 대비 Accuracy | 기준선 대비 Macro F1 | 오분류/500 |
|---|---:|---:|---:|---:|---:|
| 기존 B0·256·CE | 0.7960 | 0.7915394647566528 | - | - | 102 |
| WS-DAN | 0.7640 | 0.7546949301321499 | -0.0320 | -0.0368445346245029 | 118 |
| **PMG** | **0.8500** | **0.8473279632397033** | **+0.0540** | **+0.0557884984830505** | **75** |
| MixStyle | 0.8060 | 0.8033767539683495 | +0.0100 | +0.0118372892116967 | 97 |

PMG는 기준선보다 Accuracy가 **5.4%p**, Macro F1이 **약 5.58%p** 높았다. 오분류는
102장에서 75장으로 27장 감소했다. MixStyle도 기준선을 소폭 개선했지만 PMG보다 낮았다.
WS-DAN 응용은 이 데이터와 현재 구현 조건에서 기준선보다 낮았다.

## 4. 클래스별 F1

| 모델 | 건선 | 아토피 | 여드름 | 정상 | 주사 |
|---|---:|---:|---:|---:|---:|
| 기존 B0·256·CE | 0.7606837606837609 | 0.6847826086956522 | 0.6818181818181819 | 0.9345794392523363 | 0.8958333333333334 |
| WS-DAN | 0.7232142857142857 | 0.5750 | 0.7373737373737373 | 0.8968609865470852 | 0.8410256410256411 |
| **PMG** | **0.8252427184466019** | **0.7835051546391754** | **0.7634408602150538** | **0.9615384615384615** | **0.9029126213592233** |
| MixStyle | 0.7619047619047619 | 0.7253886010362695 | 0.7011494252873564 | 0.9383886255924171 | 0.8900523560209425 |

PMG는 기준선 대비 다섯 클래스의 F1이 모두 개선됐다. 개선 폭은 아토피 약 9.87%p,
여드름 약 8.16%p, 건선 약 6.46%p, 정상 약 2.70%p, 주사 약 0.71%p다. 특히 기존에
상대적으로 어려웠던 아토피와 여드름이 개선된 점이 최종 후보 선정의 핵심 근거다.

PMG Validation 혼동행렬의 정답 수는 건선 85장, 아토피 76장, 여드름 71장, 정상 100장,
주사 93장이다. 여전히 주요 혼동은 여드름을 건선 또는 아토피로 판단하는 경우와 아토피를
건선 또는 여드름으로 판단하는 경우다.

## 5. 학습 기록과 실행 비용

| 모델 | 선택 체크포인트 | 학습 시간 | 파라미터 수 | 저장 모델 크기 |
|---|---|---:|---:|---:|
| WS-DAN | `stage2_best.keras` | 754.3477817380001초 | 4,111,024 | 17,281,082 bytes |
| PMG | `stage2_best.keras` | 983.6290964949999초 | 8,872,375 | 36,377,179 bytes |
| MixStyle | `stage2_best.keras` | 492.14842274700004초 | 4,055,976 | 28,996,743 bytes |

PMG는 세 방법 중 학습 및 추론 구조가 가장 무겁다. 실제 추론에서는 원본 이미지 한 장을
입력하지만 세 branch logits와 fused logits를 합산하므로 기준선보다 계산량이 늘어난다.
최종 패키지에는 이 추론 규칙을 반드시 포함해야 한다.

PMG의 학습 정확도는 마지막 구간에서 0.99 이상이었고 Validation 정확도는 최고 0.85였다.
Validation loss도 epoch별 변동이 있었으므로 마지막 모델이 아니라 저장된
`stage2_best.keras`를 사용해야 한다.

## 6. 후보 고정 결정

사전에 정한 Validation Macro F1 기준에 따라 최종 Test 평가 후보를
**`pmg_b0_256_ce_seed_42`**로 고정한다.

- 선택 모델: `pmg_b0_256_ce_seed_42/attempt_a8364775fcb8/stage2_best.keras`
- Validation Accuracy: `0.85`
- Validation Macro F1: `0.8473279632397033`
- 모델 SHA-256: `83e659dd09a9355135ee0de0197037e81ece962777f59dedae8d9a37b49a3fc4`
- Test 상태: 미평가

다음 실행에서는 이 PMG 체크포인트만 고정 Test에서 한 번 평가하고, 모델·클래스 순서·256
입력 전처리·PMG 합산 추론 코드를 하나의 공개 후보 패키지로 묶는다.

## 7. 재현성과 한계

- 세 모델 모두 Validation 예측 CSV 500행, support 합계 500, 혼동행렬 합계 500이 일치했다.
- 결과 ZIP에는 보고서와 예측 기록이 있으며 `.keras` 모델 본체는 포함되지 않았다. 모델은
  Google Drive의 원래 실행 폴더에 보존되어 있어야 한다.
- 독립 공통 데이터 감사는 프로젝트 결정에 따라 생략되었다.
- 사람, 병변, 촬영 세션 단위 누수 여부는 확인되지 않았다.
- perceptual near-duplicate와 임상 라벨 검수도 수행되지 않았다.
- 현재 수치는 Validation 결과이며 최종 Test 성능으로 표현하면 안 된다.
