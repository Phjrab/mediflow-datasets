# 촬영 변화 비교 완료 후 MMD·CORAL 특징 정렬 파일럿

2026-11-09 사용자 결정 기록. 상태: **후속 실험 예정, 코드 구현·학습 미실행**.
로드맵 3·6단계의 진단에 사용한 특징 거리를, 이후 별도 학습 실험에서 손실로 사용하는 계획이다.

## 실행 순서

1. 현재 준비한 피부·얼굴·두피의 원본 재검사와 비교 학습을 완료한다.
2. Validation으로 모델을 선정하고, 선택 고정 후 원본·촬영 변화 Source Test를 평가한다.
3. 실제 사진의 예측 변화와 새 모델의 Source/Target 특징을 다시 계산해 현재 단계 보고서를 마친다.
4. 같은 분야 안에서 출발 모델·데이터·학습량을 고정하고 정렬 없는 추가 학습, MMD-only,
   CORAL-only를 각각 비교하는 후속 파일럿을 구현·실행한다.
5. 특징 거리 감소와 별개로 원본 질환 분류 성능 유지 여부를 함께 평가한다.

현재 실행 ZIP·노트북·프로필은 수정하지 않는다. 기존 모델과 결과를 보존하고 새 실험
폴더·설정·체크포인트·보고서로 기록한다. 현재의 "특징 정렬 학습 보류" 기록은 당시 상태이며,
이번 결정은 현 단계 완료 후 그 실험을 별도로 진행한다는 후속 일정이다.

## 비교 조건

skin, web_skin, hair를 독립 실험으로 취급한다. Hair 5/6클래스를 바꾸거나 섞지 않는다.
출발 모델은 현재 단계의 Validation 선정 기록으로 고정하며 Test 결과로 다시 고르지 않는다.

| 비교군 | Source 분류 손실 | 추가 정렬 손실 |
|---|---|---|
| 정렬 없는 추가 학습 대조군 | 분야별 기존 분류 손실 유지 | 없음 |
| MMD-only | 대조군과 동일 | MMD |
| CORAL-only | 대조군과 동일 | CORAL |

첫 비교에서는 두 정렬 손실을 동시에 추가하지 않는다. 같은 출발 가중치, 데이터 버전·분할,
클래스 순서, 입력 정책·촬영 변환, seed, optimizer, 학습 가능 층과 Source 업데이트 수를
고정한다. 단순히 추가 학습을 더 한 효과가 정렬 효과로 보이지 않도록 대조군도 같은 학습량을
사용한다. 시험 변수는 정렬 손실의 유무·종류이며 필요한 동반 변경과 이유를 별도 기록한다.

정렬할 특징 층, 손실 가중치, MMD 커널·범위 설정, Source/Target 표본 추출 방식은 아직
확정하지 않았다. 현재 모델 결과와 Train 특징을 확인한 뒤 사전 설정하고 Validation으로만
선정한다. 이미 확인한 Source Test 점수에 맞춰 이 값을 반복 조정하지 않는다.
새 실험의 최종 Test 평가는 설정과 선택을 고정한 뒤 수행하며 과거 Test를 독립적인 새 자료처럼
표현하지 않는다.

## 실제 촬영 사진의 역할

현재 4명의 124장은 촬영 특성 조사에 사용한 자료이며 질환 정답은 미확인이다.
후속 정렬 학습에서 사용하면 Target 학습 자료라는 역할을 추가 기록한다. 원본 파일·과거 역할
기록은 보존하고, 그 사진을 독립 Target Test로 다시 명명하지 않는다.
별도로 확보한 Target Test는 학습·손실 가중치 선정에 사용하지 않는다.

Target 사진에 질환·정상 라벨이나 모델 예측을 임의의 정답으로 붙이지 않는다.
라벨 없는 정렬 실험을 진행하더라도 Target Accuracy·Macro-F1은 계산할 수 없다.
현재 작은 인원과 Source/Target의 미확인 클래스 구성은 계속 제한으로 기록한다.
Skin과 Hair 5클래스에는 정상 클래스가 없으므로 일괄 정렬로 질환 특징이 손상되는지도 검토한다.

## 평가와 결과 기록

- 원본 Source Accuracy·Macro-F1·클래스별 Recall·혼동행렬.
- 별도 표시한 촬영 변화 Source 평가와 기존 분류 성능 저하 여부.
- 동일 조건에서 다시 추출한 Source/Target 특징 분포와 MMD·CORAL.
- 실제 촬영 사진의 예측 변화. 정답 없는 사진의 확신도 증가를 정확도 개선으로 해석하지 않음.
- 데이터·분할·출발 체크포인트·환경·commit·미커밋 코드·seed·설정·선정 이유·실패 사례.

특징 거리가 줄어도 질환 분류가 좋아졌다고 단정하지 않는다. 성능이 떨어지거나 정렬 효과가
분명하지 않으면 미채택 결과로 보존한다. 실제 환자 성능의 검증에는 정답이 확인된 독립 실제
장비 사진이 필요하다. 이번 결정으로 그러한 자료가 확보됐거나 정렬 학습이 완료됐다고
보고하지 않는다.
