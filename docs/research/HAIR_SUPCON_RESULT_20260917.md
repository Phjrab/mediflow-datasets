## 1. 실험 목적

Hair 데이터의 미세각질과 비듬처럼 시각적으로 비슷한 클래스를 더 잘 구분할 수 있는지
확인하기 위해 Supervised Contrastive Learning(SupCon)을 기존 분류 학습과 비교했다.
SupCon은 같은 클래스의 특징 표현을 가깝게, 다른 클래스의 특징 표현을 멀게 학습하는
방법이다. 근거 논문은 Khosla et al., *Supervised Contrastive Learning*, NeurIPS 2020이다.

## 5. 해석과 결정

이번 결과는 SupCon이 Hair의 유사 클래스 구분에 도움이 될 가능성을 보여준다. Accuracy,
Macro F1, 모든 클래스 F1과 목표 혼동 수가 같은 방향으로 개선됐기 때문에 seed 43·44 확인
실험으로 진행할 근거가 있다.

다만 seed 42 한 번의 결과이므로 SupCon이 최종적으로 더 좋다고 확정하지 않는다. 다음에는
기준선과 SupCon을 각각 seed 43·44로 반복하고, seed 42·43·44의 Validation Macro F1 평균과
표준편차를 비교한다. 그 비교가 끝나기 전에는 Test 평가나 공개 후보 교체를 하지 않는다.

## 6. 검증 범위와 제한

- 두 `validation_predictions.csv`는 각각 1,252행이며 모두 Validation 경로였다.
- 저장된 예측 클래스는 각 행의 가장 큰 출력값과 일치했고, 재계산한 Accuracy는 결과 JSON과 일치했다.
- ZIP 34개 파일의 CRC 검사를 통과했다.
- 데이터 ZIP 해시는 기록된 기대값과 일치했다.
- 이번 실행에서는 사용자 결정에 따라 독립 데이터 감사 폴더를 사용하지 않았다.
- 사람·병변·촬영 세션 단위 누수는 식별 정보가 없어 확인할 수 없었다.
- 임상 라벨의 정확성과 지각적 근접 중복은 이번 실행에서 새로 검증하지 않았다.
- Test는 사용하지 않았다.
- 로컬 결과 ZIP에는 보고서와 재현 기록만 있으며 `.keras` 모델은 포함되지 않았다. 모델은 Drive 실행 결과에 유지된다.
