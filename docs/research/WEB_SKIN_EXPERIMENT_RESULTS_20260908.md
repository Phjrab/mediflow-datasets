# Web Skin 자동 실험 결과 분석 (2026-09-08)

## 결론

6개 실험이 기록대로 완료됐다. 사전에 정한 Validation Accuracy 및 동점 시 먼저 실행된 후보 유지 규칙에 따라 **EfficientNet-B0 / 256 / Cross Entropy**가 선택됐다. 선택 체크포인트는 Stage 2의 8번째 Epoch(표시상 전체 23번째)다. Test는 400장 중 353장 정답, **Accuracy 0.8825 (88.25%)**, Macro F1 **0.8813822927981046**이다.

B1과 추가학습 보존 모델은 Validation Accuracy가 같지만, B1의 Macro F1이 조금 높다는 이유로 사후에 선택 기준을 변경하지 않았다. B1 연장 행은 새 연장 체크포인트 성능이 아니라 부모 최고 모델을 보존한 결과다.

## 변경 조건별 해석

1. **부분 미세조정:** 모든 새 모델에서 Stage 1보다 Stage 2 최고 Validation Accuracy가 높았다. 선택 B0 256은 Stage 1 기록 0.7039999961853027에서 Stage 2 기록 0.7960000038146973으로 상승했다. 계층 해제뿐 아니라 추가 학습량·학습률 변경이 함께 포함된 효과다.
2. **해상도:** B0 CE 224의 397/500에서 256의 398/500으로 정답이 한 장 늘었다. Macro F1은 오히려 224 쪽이 조금 높다. 이 단일 실행만으로 256이 확실히 우수하다고 단정하지 않는다.
3. **Loss:** B0 256에서 CE 398장, LS 397장, Focal 396장 정답이다. 이번 실행에서는 LS/Focal의 추가 이득이 관찰되지 않았다. 각 Loss의 절대 크기는 서로 다른 계산식이므로 직접 순위화하지 않는다.
4. **Backbone:** B0 256 LS의 397장에서 B1 LS의 398장으로 한 장 증가했다. B1의 Macro F1은 CE 후보보다 높지만 Accuracy가 동점이다. B0 파라미터는 4055976개, B1은 6581644개다. 속도 우위는 별도 벤치마크 없이 주장하지 않는다.
5. **추가 학습:** B1 연장 구간 자체의 최고 Validation Accuracy는 0.7900000214576721이다. 부모 최고 0.7960000038146973을 넘지 못해 부모 모델을 그대로 보존했다. 두 행의 모델 해시 및 Validation 예측이 같다는 점을 확인했다.

## 학습곡선 및 과적합 해석

모든 실험에서 미세조정 후 Train/Validation Loss가 대체로 감소한다. 학습 실패나 수치 발산은 관찰되지 않았다. 후반부에는 Train Accuracy가 더 오르는 동안 Validation Accuracy가 정체되는 경향이 있다.

특히 B1 연장의 마지막 Train Accuracy는 0.9031944274902344, Validation Accuracy는 0.7860000133514404다. Validation Loss는 0.671500027179718에서 0.6627480983734131로 감소했으므로 Loss가 급증하는 심한 과적합으로 단정할 수 없다. 다만 정확도 관점에서 추가 학습 이득이 없고 Train/Validation 격차가 커지는 징후가 있다.

선택된 B0 256은 마지막 모델이 아니라 8번째 미세조정 Epoch의 최고 모델이다. 마지막 Epoch의 Validation Accuracy 0.7919999957084656보다 좋은 체크포인트를 보존하는 동작이 제대로 적용됐다.

Test 오답은 47장이다. 가장 많은 단방향 혼동은 아토피→건선 9장이다. Validation에서는 여드름→건선 22장, 아토피→건선 18장, 여드름→아토피 14장이 두드러진다. 다음 오류 분석의 우선순위는 Validation의 아토피·여드름·건선 혼동이다. Test 오답에 맞춰 설정을 반복 변경하지 않는다.

정상은 Test 80장 모두 맞혔지만 질환 이미지 3장을 정상으로 예측했다. 정상 클래스 Recall 1.0이 정상 예측의 완전한 정확성이나 실제 질환 누락 없음으로 해석되어서는 안 된다.

Validation 0.796과 Test 0.8825의 차이는 관측된 두 분할 간 성능 차이다. 클래스 수는 균형이지만 개별 표본 난도·출처·사람·촬영 조건은 같다고 보장되지 않는다.
