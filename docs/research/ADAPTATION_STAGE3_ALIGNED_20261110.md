# 3차 특징 정렬 학습

2차와 같은 피부 기본, 얼굴 선정, 두피 선정의 **1차 학습 전 저장본**에서 시작한다.
같은 공통 ZIP v3, 데이터 분할, 입력 크기, 클래스 순서, 확장 변환, seed 42, Adam 학습률
0.00001, 모델당 5 epoch, 배치 크기와 Source 갱신 횟수를 쓴다. 2차 모델은 검증 비교에 쓴다.

추가하는 조건은 **MMD와 CORAL을 함께 학습 손실에 넣는 것**이다. 피부·두피는 분류 전 평균
풀링 특징, 얼굴 PMG는 `pmg_fusion` 특징을 정렬한다. PMG는 기존 네 갱신을 유지하며 마지막
결합 갈래에 두 손실을 더한다. 정렬이 있는 배치에서는 Source의 질환 분류 손실과 두 분포 손실을
합산해 같은 옵티마이저 갱신에 넣는다.

고정 특징 좌표는 시작 모델과 클래스별 최대 8장의 원본 Source Train에서 구한다. MMD는
제곱 거리의 기준 폭과 그 0.25배·1배·4배 RBF 커널 평균을 쓴다. CORAL은 같은 좌표에서
공분산의 차이를 계산한다. 각 손실은 시작 Source Train 분류 손실의 5%에 맞춰 초기 크기를
조정하고, 가중치 상한 10을 적용한다. 실제 가중치와 계산 근거는 `alignment_setup.json`에 저장한다.
정렬 배치마다 참여자 네 명에게서 한 장씩 뽑고, 한 epoch 안에서 사진을 반복 사용하지 않는다.
전체 Source 배치 중 일부에만 적용하며 라벨 없는 촬영본에는 질환 분류 손실을 적용하지 않는다.

피부 42장, 얼굴 42장, 두피 40장의 암호화된 사진 입력은 기존 공통 ZIP에 있다. 키는 Colab의
가려진 입력을 통해 프로세스에 전달한다. 복호화된 사진은 학습 프로세스의 메모리에서 사용하며
Drive 결과에는 검증 점수, 특징 거리, 참여자 합산 예측 건수와 예측이 달라진 장수만 남긴다.
촬영본은 네 명의 정렬 학습 자료를 재사용한 진단이다. 정답이 없어 Target Accuracy는 비워 둔다.

원본·조명 변환·확장 변환 Validation에서 시작 저장본, 1차, 2차, 3차를 비교한다. 최적 회차는
원본·확장 검증 Macro-F1 중 낮은 값이 가장 큰 회차다. 동점이면 원본 점수를 사용한다.
분류 결과와 특징 거리를 따로 해석한다. 클래스별 Recall과 혼동행렬은 `complete.json`에 있다.
Source Test는 후속 최종 비교에서 사용한다. 두 정렬 손실을 묶은 실험이며 각 손실의 효과는
분리해서 측정하지 않는다. 현재 Validation의 과거 체크포인트 학습 노출 여부는 미확인이다.

1. [3차 노트북](../../notebooks/camera_adaptation/MediFlow_Adaptation_Stage3_Aligned_20261110.ipynb)을
   Colab에서 열고 GPU 선택 후 **모두 실행**한다.
2. Drive 연결 후 로컬 `camera_capture/_review/MediFlow_Stage3_Target_Key_20261110.txt`의
   한 줄을 가려진 입력란에 붙여 넣는다. 공통 ZIP과 1·2차 완료 기록은 기존 Drive 경로에서 읽는다.
3. `MediFlow_adaptation_runs/4ae6e07eb4af1225/stage3`에서 비교표, 학습곡선, 분야별
   `best.keras`, `aligned/history.json`, `feature_comparison.json`을 확인한다.
   같은 노트북으로 다시 실행하면 완료 분야는 재사용하고 미완료 분야는 저장된 epoch부터 이어간다.
