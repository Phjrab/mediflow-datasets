## 3. 실제 측정한 차이

아래 값은 이미지별 지표의 중앙값이다. Target은 네 참여자·두 조건, 총 여덟 그룹의
중앙값 범위를 썼다. 읽기 편하게 소수 둘째 자리까지 표시했으며 정확한 값과 분위수·분산은
각 `analysis/analysis.json`과 위의 요약 JSON에 보존했다. 이 표는 분류 성능 지표가 아니다.
영역은 모델 입력 크기로 변환한 뒤의 얼굴 양쪽 볼 또는 현미경 중앙부다.

| 분야·지표 | Source Train 중앙값 | Target 그룹 중앙값 범위 | 해석 |
|---|---:|---:|---|
| 얼굴 밝기 | 170.89 | 82.14–138.75 | 실제 볼 영역이 어둡다. Source 얼굴 검출 성공 3,048/3,600장 기준이다. |
| 얼굴 너비/화면 너비 | 0.74 | 0.22–0.30 | 실제 사진에서 얼굴이 차지하는 비율이 작다. |
| 피부 밝기 | 88.32 | 151.87–157.68 | 기존 병변과 촬영 팔 피부의 내용 차이가 함께 들어 있다. |
| 피부 대비 | 65.43 | 19.08–26.49 | 실제 영역의 명암 차이가 작지만 질환·부위 차이를 분리하지 못했다. |
| 두피 밝기 | 158.91 | 161.75–188.35 | 실제 영역이 대체로 밝다. 흰 두피·검은 모발 구성의 영향도 있다. |
| 두피 대비 | 63.77 | 145.20–189.65 | 큰 차이가 있으나 조명·모발·두피 노출의 원인을 나눠 확인해야 한다. |
| 두피 미세 경계량 | 7.82 | 7.33–11.18 | 범위가 겹친다. 카메라 초점 성능의 단독 지표로 해석하지 않는다. |
| 두피 어두운 경계 비율 | 0.13 | 0.10–0.16 | Source 전체와 겹친다. 모발 면적을 직접 분할한 값은 아니다. |

예시 몇 장만 본 때와 달리, 전체 두피 Train에서는 어두운 모발 경계와 미세 경계량이 Target과
겹친다. 따라서 이전 예시 비교에서 보인 “촬영 사진에 모발이 더 많음”을 전체 데이터에
일반화하지 않는다. 색·질감 차이 전체를 카메라 보정량으로 사용하는 것도 보류한다.

## 4. 변환 초안과 육안 검토

프로필은 여전히 `train_visual_review=pending`으로 보존했다. 아래는 완료된 학습의 설정이나
장비의 보편적인 상수가 아니라, 실제 측정값에 제한과 완화를 적용한 **학습 전 초안**이다.

| 분야 | 현재 초안 | 검토 결과 |
|---|---|---|
| 얼굴 | 밝기 −32.0~−25.583170413970947, 대비 1.15, 가로 크기 0.6721115537848605~0.6946879150066401, 세로 0.8059760956175299~0.8461118489006936, 좌우 조명 13.643229007720947~14.992496490478516 | 얼굴 축소 주위에 인위적인 단색 테두리가 생긴다. 가로·세로 축소율도 달라 형태가 변한다. 현재 구도 변환을 학습용으로 확정하지 않는다. |
| 두피 | 밝기 −0.6363735198974609~12.4506196975708, 나머지는 항등 변환 | 다섯 Train 표본에서 밝기 변화가 작다. 현재 복합 변환은 밝기만 변환과 동일하다. |
| 피부 | 밝기 −1.3492517471313477~−0.7292451858520508, 대비 0.9399699904076788~0.957350048293398 | 열 Train 표본에서 큰 형태 손상은 눈에 띄지 않으나 변환 자체가 작다. Source–Target 전체 차이를 해결했다고 볼 수 없다. |

두피 프로필은 대비·크기·조명이 모두 항등값이므로 동일 seed의 `brightness_only`와
`target_guided` 출력이 같다. 임의 RGB 입력과 10개 seed로 확인한 최대 차이는 `0.0`이다.
이는 실행 논리 확인이며 질환 학습 결과가 아니다. 현재 조건 그대로 두 군을 서로 다른
방법의 비교 실험으로 해석하지 않는다. 유의미한 별도 변환 근거를 확보하거나 중복 조건을
합치는 방식으로 다음 실험 구성을 정리해야 한다.

피부·두피 프로필이 보수적인 이유는 질환 학습 사진과 라벨 미확인 촬영 부위가 달라
색·질감을 카메라 영향으로만 특정하기 어렵기 때문이다. 이 초안을 전체 Domain Adaptation이
완성됐다는 의미로 표현하지 않는다. 얼굴 변환의 인위적 배경도 학습 전에 수정·검증해야 한다.

## 5. 특징 분포

Hair/Skin은 전체 Train 통계와 별도로 클래스당 8장씩 특징을 추출했다.
두피 Source 특징 40장·Target 40장, 피부 Source 80장·Target 42장이다.

| 분야 | 이미지별 MMD² | 이미지별 CORAL | Target을 참여자별 평균으로 묶은 MMD² |
|---|---:|---:|---:|
| 두피 | 0.4095595573131235 | 0.18066580827856996 | 0.6068357780943071 |
| 피부 | 0.40420648571778206 | 0.2656954007224258 | 0.5296546916217382 |

이는 특징 분포 거리이며 정확도가 아니다. 서로 다른 모델·기준 표본이므로 분야 간 순위를
매기지 않는다. 예시 기반 이전 수치보다 작아도 모델이 학습으로 개선됐다는 의미가 아니다.
Web Skin의 간단 검토 ZIP에는 PCA 그림은 있으나 `feature_diagnostics.json`이 없어,
이번 전체 Source 표본 기반 MMD/CORAL 수치는 이 보고서에서 보충하거나 추정하지 않았다.

## 6. 유사 사진 후보와 남은 순서

현재 검사는 9×8 축소 명암 패턴의 64-bit dHash 해밍 거리 3 이하를 후보로 남긴다.
Original/Augmented 폴더명을 제외한 경로로만 묶으면 얼굴 484쌍은 159개 경로 그룹,
피부 7,770쌍은 2,556개 경로 그룹으로 정리된다. **이것은 검토 목록 정리일 뿐 실제 이미지
내용의 중복 판정이나 승인 수가 아니다.** 후보를 해제하는 JSON을 만들지 않았다.

다음 순서로 진행한다.

1. 후보 사진을 원본·증강 이력과 더 높은 해상도에서 대조하고, 실제 파생본과 다른 사진을 구분한다.
   지금 검토 ZIP에는 후보 사진 원본 전체가 없어 이 작업은 아직 완료하지 못했다.
2. 얼굴의 인위적 테두리·형태 변화 문제와 두피의 동일 실험 조건을 정리한다.
   추가 변수는 측정 근거가 있을 때만 채택한다.
3. Train 표본과 분할 점검 결과를 기록하고 실험 조건을 고정한 뒤 추가 학습한다.
4. Validation으로 후보를 고정한 뒤 원본 Source Test와 변환 복사본을 별도로 평가한다.
   실제 촬영 사진은 예측·특징 변화를 확인하며 질환 정답 없이는 Target 정확도를 계산하지 않는다.

촬영 원본, 기존 데이터셋, 모델, 기존 보고서는 수정하거나 삭제하지 않았다.
