# Hair ‘양호’ 후보 데이터 검증과 6-class v2 구성 계획

상태: **원본 ZIP 1차 점검 완료, 데이터셋 구축 전**. 사용자는 처음 확보한 약 2,400장의 여섯 증상값이 모두 `0`임을 확인했고, 정리 전 원본도 보관하고 있다. 파일명이 겹친 항목의 사진 내용도 직접 보고 동일함을 확인했다. 업로드한 ZIP에서는 JPG **534장**을 확인했다. 단독 검사 결과와 한계는 [1차 점검 보고서](HAIR_GOOD_UPLOAD_AUDIT_20260928.md)에 기록했다. 기존 Hair ZIP과의 교차 검사, 분할, 증강, 재학습은 수행하지 않았다.

## 먼저 확인할 점

AI Hub ‘유형별 두피 이미지’는 미세각질·피지과다·모낭사이홍반·모낭홍반/농포·비듬·탈모를 각각 `0`~`3` 값으로 기록한다. 사용자가 확보한 후보의 **여섯 증상값은 모두 `0`**이라고 확인했다. 데이터 소개 페이지의 별도 `양호` 통계는 811건이다. 업로드한 ZIP의 JPG 534장은 읽기·완전 중복 검사를 통과했으나, 라벨 JSON이 없어 값 `0`의 파일별 재확인과 기존 Hair 데이터와의 겹침 검사는 남아 있다.

1. 사진마다 원본 JSON의 여섯 `value_*` 값과 이미지 ID, 비식별 사람 ID, 단말기·촬영 일련번호를 가능한 범위에서 연결한다. 사용자가 확인한 전 항목 `0` 조건을 파일 수준에서 재검사하고 누락·불일치·중복 라벨을 보고한다.
2. 적격 사진을 원천 데이터 기준의 `양호` 클래스로 구성한다. 촬영 조건과 샘플을 육안 검수하며, 이 라벨을 의학적 질환 부재의 증명으로 확대 해석하지 않는다.
3. 파일 검사에서 값이 하나라도 다른 사진이 발견되면 해당 사진만 별도 검토 대상으로 격리한다.
4. 기존 Hair Clean v1의 5종과 새 후보 사이에서 파일 바이트·RGB 픽셀·유사 사진·사람·촬영 세션·증강 유래 중복을 확인한다. ID가 없으면 사람/세션 수준의 누수는 미확인으로 기록한다. 정리 전 원본은 복구 가능한 백업으로 보존한다.

## 보관과 생성

- Drive의 기존 `hair_datasets`(확장자 없는 ZIP 파일)는 변경하지 않는다. 직접 사진을 확인해 정리한 **534장**을 별도의 `hair_good_raw_v1.zip`으로 보관한다. 이 ZIP에는 대응 JSON이 없다. 정리 전 약 2,400장 원본은 사용자 백업으로 남긴다. 원본 ZIP을 Drive에서 미리 풀 필요는 없다.
- Colab 준비 코드가 기존 ZIP과 새 ZIP **두 개를 읽어 검사**한다. 검증 후 `hair_clean_v2_6class.zip` 하나를 새로 만들고, 클래스 순서·원천 파일·분할·증강 출처·제외 이유·파일 해시를 기록한다.
- 기존 공통 학습 노트북은 데이터 ZIP 하나와 고정된 5-class 계약을 전제로 하므로 두 원본 ZIP을 그대로 지정하거나 `DATA_ZIP`만 바꿔서 6-class 학습할 수 없다. 새 v2 학습 코드를 별도로 준비한다.

## 분할과 증강

- 사용 가능하다고 확인된 **원본**을 먼저 사람/촬영 세션 단위로 Train·Validation·Test에 나눈다. 기존 5종과 새 ‘양호’ 후보를 모두 포함하는 v2 분할을 새로 기록한다. 그룹 ID가 없을 때는 가능한 중복 검사 범위와 남는 한계를 명시한다.
- 기존처럼 80:10:10을 목표로 하되 그룹 단위 배정과 기존 데이터와의 중복 확인 후 실제 수량을 확정한다. JPG 534장만 사진 단위로 나누면 대략 427/53/54장이지만, **105개 비식별 ID를 묶어 분할하므로 확정 수량이 아니다**. 작은 Validation/Test에서는 몇 장의 오분류만으로 지표가 크게 달라질 수 있어 클래스별 정답 수와 혼동행렬을 함께 보고한다.
- 증강은 **Train 원본에만**, 기존 Hair와 같은 계열의 약한 밝기·대비·회전·초점 변화 등을 적용한다. Validation/Test는 원본으로 유지한다. 정상 원본이 적다고 증강 이미지를 서로 독립된 새 사람처럼 세거나 Validation/Test로 복사하지 않는다.
- 기존 Hair Clean v1에서는 Train 원본 10,032장에 증강 5,015장을 더했다. 새 `양호` 원본은 질환별 약 2,000장보다 적으므로 v2에서도 무조건 50%를 기계적으로 맞추거나 증강 사진을 새 사람처럼 세지 않는다. 적격 원본 수, 그룹 분포와 클래스 불균형을 확인해 증강량·학습 가중치를 별도 실험 조건으로 정한다.

## 평가 원칙

기존 5-class 후보와 새 6-class 후보는 출력 문제가 다르다. 두 후보의 Accuracy 숫자 차이를 정상 클래스 추가의 순수 효과로 해석하지 않는다. 6-class v2의 기준 모델을 먼저 만들고, 이후 구조 비교 실험은 동일 v2 분할·동일 클래스 순서·동일 평가 규칙에서 모델 구조를 바꿔 비교한다. 설정 선택에는 Validation을 쓰고 고정한 후보만 Test에서 평가한다.
