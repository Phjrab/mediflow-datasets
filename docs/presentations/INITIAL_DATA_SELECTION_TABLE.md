# MediFlow 초기 데이터 수집·클래스 선정표

## 발표 시점

이 표는 **초기 데이터를 수집하고 이미지를 직접 검수하여 클래스를 선정한 단계**만 설명한다.

- Skin: 원천 클래스 선정과 첫 학습 데이터 구성 단계
- Hair: 원천 증상을 검수하고 5개 클래스로 구성한 단계
- Web Skin: 데이터 출처만 확인한 후속 후보. 이 시점에는 학습에 사용하지 않음
- Train·Validation·Test 중복 검사와 Clean 데이터 재구성은 아직 시행하지 않은 시점

| 이 시점에서 표현하지 않을 내용 | Web Skin 5종 선정, 4,500장 분할, 증강, 학습 성능 |

## 5. 발표용 문장

> 초기에는 AI Hub에서 피부종양과 두피 이미지를 확보한 뒤 클래스별 이미지를 직접 검수했다. Skin은 15개 클래스 중 시각적으로 구분하기 어려운 항목을 제외하고 10개를 선정했다. Hair는 양호·경증을 제외하고 중등도·중증을 중심으로 구성했으며, 모낭홍반/농포는 모낭사이홍반과 시각적으로 비슷해 제외했다. 이 단계에서 Web Skin은 후속 후보일 뿐 아직 학습에 사용하지 않았고, 데이터 중복 검사도 아직 시행하지 않았다.
