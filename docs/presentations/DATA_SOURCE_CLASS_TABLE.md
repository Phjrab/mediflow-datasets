# MediFlow 원천 데이터·클래스 선정·사용 수량표

이 문서는 발표에서 `사이트 원천 수량`, `MediFlow가 선택한 클래스`, `실제 학습 데이터에 넣은 수량`을 구분하기 위한 표다.

## 1. 전체 요약

| 도메인 | 원천 데이터 | 사이트 제공 규모 | MediFlow 선택 | 초기 실제 사용 | Clean 원본 |
|---|---|---:|---:|---:|---:|
| Skin | AI Hub 피부종양 이미지 합성 데이터 71864 | 15종 × 1,000장 = 15,000장 | 10종 × 1,000장 = 10,000장 | 10종 × 900장 = 9,000장 | 8,949장 |
| Web Skin | AI Hub 안면부 피부질환 이미지 합성 데이터 71863 | 6종 × 2방향 × 1,000장 = 12,000장 | 정면 5종 × 1,000장 = 5,000장 | 5종 × 900장 = 4,500장 | 기존 분할 유지 |
| Hair | AI Hub 유형별 두피 이미지 216 | 고유 두피 이미지 101,027건 | 5종의 중등도·중증 후보 18,729장 | 5종 × 2,900장 = 14,500장 | 12,536장 |

Skin과 Web Skin의 `클래스당 1,000장`은 AI Hub의 원천 수량이고, `클래스당 900장`은 프로젝트 분할에 실제로 넣은 수량이다. 나머지 100장을 제외한 세부 기준은 현재 기록에 남아 있지 않다.

## 4. Hair 원천 라벨

출처: [AI Hub 유형별 두피 이미지](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=216)

| AI Hub 원천 라벨 | AI Hub 증상별 통계 | MediFlow 사용 | 중등도·중증 선별 후 후보 | 초기 균형화 사용 |
|---|---:|---|---:|---:|
| 미세각질 | 17,434 | 사용 | 2,936 | 2,900 |
| 피지과다 | 80,416 | 사용 | 3,746 | 2,900 |
| 모낭사이홍반 | 67,414 | 사용 | 4,275 | 2,900 |
| 모낭홍반/농포 | 4,592 | 미사용 | 기록 없음 | 0 |
| 비듬 | 40,482 | 사용 | 2,900 | 2,900 |
| 탈모 | 25,682 | 사용 | 4,872 | 2,900 |
| 양호 | 811 | 미사용 | 기록 없음 | 0 |

Hair의 AI Hub 증상별 통계는 서로 배타적인 클래스 수량이 아니다. 한 두피 이미지에 여러 증상 값이 함께 표시될 수 있으므로 17,434·80,416 등을 더해서 원천 이미지 수라고 표현하지 않는다. AI Hub가 밝힌 고유 두피 이미지는 101,027건이다.

MediFlow는 양호·경증을 제외하고 중등도·중증을 사용했다. `모낭홍반/농포`는 `모낭사이홍반`과 사진상 특징이 유사해 제외했다. 나머지 5종은 가장 적은 비듬 2,900장에 맞춰 클래스당 2,900장으로 균형화했다.

## 5. 발표용 핵심 문장

> Skin은 AI Hub의 피부종양 합성 데이터 15종 중 10종을, Web Skin은 안면부 합성 데이터에서 지루와 측면을 제외한 정면 5종을 사용했다. 두 데이터의 원천은 각 클래스당 1,000장이었고, 프로젝트 분할에는 클래스당 900장을 사용했다. Hair는 AI Hub의 101,027건 두피 이미지에서 양호·경증을 제외하고 5개 증상의 중등도·중증 이미지를 선별한 뒤, 가장 적은 클래스에 맞춰 각 2,900장으로 균형화했다.
