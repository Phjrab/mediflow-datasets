# Hair 고급 기법 후속 실험 — 보류 기록

작성일: 2026-09-07. 사용자가 추후 진행하기로 한 연구 후보이며, 아래 기법의 구현·학습·성능 개선은 아직 수행하지 않았다.
현재 B1 공개 데이터 후보 및 원본 실험 결과를 보존한다. 다음 작업 대상은 별도 분야인 Web Skin이다.

## 문제와 근거

256 B0 CE 오답 감사에서는 Test 1,252장 중 오답이 263장이었다.
비듬→미세각질 38장, 미세각질→비듬 31장, 비듬→피지과다 23장,
피지과다→비듬 13장으로 네 유형이 105장을 차지했다.
시각적 유사성은 중요한 원인 후보지만, 이 결과로 80%를 성능 상한이라고 단정하지 않는다.
미세 정보 손실, 라벨 오류, 여러 상태의 동시 존재, 사람·촬영 세션 간 겹침을 구분해야 한다.

## 제안된 순서

### 1. Train/Validation 라벨·영상 품질 점검

- 파일 중복 정리와 의미상 라벨 검증은 다르다. 잘못된 정답, 흐림, 반사광, 판단 부위가 없는 사진을 검토한다.
- Confident Learning으로 의심 표본의 검토 우선순위를 만든다.
- Train 내부 교차검증에서 해당 사진을 학습하지 않은 모델의 예측을 사용한다.
- 증강본과 원본은 같은 fold에 묶어야 한다. 원본 연결 기록을 활용한다.
- 의심 표본이라는 이유로 자동 삭제·라벨 변경하지 않는다. 원천 라벨 또는 전문가 확인 근거를 남긴다.
- Test 오답을 보고 그 사진만 제거하여 점수를 높이지 않는다. 평가 라벨 수정이 필요하면 별도 버전으로 근거와 전후 결과를 남긴다.

근거: [Confident Learning](https://arxiv.org/abs/1911.00068).

### 2. 전체 이미지와 부분 확대를 함께 학습

- 원본 이미지 해상도가 충분한지 먼저 확인한다. 이미 축소된 이미지를 확대한다고 세부 정보가 복구되지는 않는다.
- 전체 이미지로 분포·모발 상태를, 여러 부분 이미지로 각질·피지·모낭 주변 특징을 본다.
- Attention 기반 MIL은 여러 부분의 특징을 모아 사진 전체를 분류하는 후보다.
- 부분마다 사진 전체의 라벨을 무조건 부여하지 않는다. 실제 병변이 없는 부분도 있을 수 있다.
- 전체 사진만 사용하는 기준선과 비교한다. Backbone, Loss, 원본 단위 분할을 고정하고 부분 정보 추가 효과를 검토한다.
- 부분의 수, 위치, 크기, 결합 방법, 추론 시간·메모리를 기록한다.
- Hair에서의 개선은 아직 검증되지 않은 적용 가설이다.

근거: [Attention-based Deep Multiple Instance Learning](https://proceedings.mlr.press/v80/ilse18a.html).

### 3. 지도 대조학습(Supervised Contrastive Learning)

- 같은 클래스의 특징을 가깝게, 다른 클래스의 특징을 멀게 학습한다.
- 미세각질·비듬처럼 유사한 클래스의 표현을 구분할 수 있는지 검토한다.
- 라벨 오류가 있으면 잘못된 구분을 강화할 수 있어 라벨 점검 뒤에 진행한다.
- 데이터, Backbone, 해상도와 증강을 고정하고 대조학습 목적함수 추가를 실험한다.
- 추가 학습 단계·계산량이 필요하면 동반 변경으로 기록하고 예산을 맞춘 기준선과 비교한다.
- 전체+부분 학습과 처음부터 동시에 적용하지 않는다.

근거: [Supervised Contrastive Learning](https://arxiv.org/abs/2004.11362).

### 4. 다중 라벨 학습 — 원천 라벨 확보 후

- 현재는 다섯 상태 중 하나만 고르는 Softmax 분류다.
- 원천 JSON 또는 전문가 확인으로 복수 상태의 정답을 확보한 경우 각각의 존재 여부를 출력하는 구조를 검토한다.
- 폴더 라벨만으로 다른 상태의 존재·부재를 추정하지 않는다. 미기록 상태를 음성으로 단정하지 않는다.
- 기존 5-class Accuracy와 다중 라벨 지표는 같은 과제가 아니므로 직접 우열 비교하지 않는다.
- 클래스별 Precision/Recall, F1, PR-AUC 및 Validation에서 정한 임계값을 별도로 기록한다.

## 효과 확인 원칙

- 기존 B1 후보를 대조 모델로 보존한다.
- 작은 성능 차이는 여러 Seed 반복으로 안정성을 확인한다. 한 번의 최고 점수로 우월성을 단정하지 않는다.
- Validation으로 선택하고, 미세각질·비듬 F1 및 혼동 감소를 함께 본다.
- 기존 Test는 이미 여러 번 확인했다. 결과는 탐색적 비교로 취급하고 향후 독립 실제 장비 검증을 확보한다.
- 정답률 목표(예: 90%)를 보장하지 않는다.
- 실제 USB 현미경·사람/세션 단위 누수 검증은 여전히 별도 과제다.
