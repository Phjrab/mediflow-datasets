# Codex 작업 프롬프트 템플릿

새 작업을 시작할 때 아래 내용을 복사한 후 `[이번 작업]` 부분만 바꿔 사용한다. 저장소의
상시 규칙은 `AGENTS.md`에 있으므로 매번 긴 연구 배경을 반복할 필요는 없다.

```text
이 저장소의 AGENTS.md, docs/research/PROJECT_BACKGROUND.md, docs/ROADMAP.md를 먼저 읽고 작업해줘.

[이번 작업]
여기에 원하는 작업을 쉬운 말로 작성한다.

작업 전에는 다음을 짧게 설명해줘.
- 현재 로드맵 단계
- 이번 작업의 목적
- 변경할 파일이나 외부 시스템

작업 후에는 반드시 다음 형식으로 설명해줘.
1. 현재 단계
2. 이번에 한 일
3. 확인 결과
4. 다음 단계와 그 이유
5. 내가 직접 해야 할 일(없으면 없음)

기술 용어는 처음 사용할 때 쉬운 말로 설명하고, 완료된 작업과 앞으로 할 작업을 구분해줘.
실제로 실행하지 않은 학습, 테스트, 업로드, 커밋, 푸시는 완료했다고 말하지 마.
실험에서는 한 번에 하나의 조건만 변경하고, 고정한 조건과 변경한 조건을 알려줘.
```
