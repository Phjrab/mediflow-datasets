## 원래 14단계와 현재 상태

| 단계 | 상태와 남은 범위 |
| --- | --- |
| 1. 모델·평가 재현 | 모델 계약·저장 예측 검산 완료. 과거 원본 Test 일부의 실제 추론 재현은 원천 자료가 필요하다. |
| 2. 실제 장비 검증 자료 | 환경 조사 사진 수집 완료. 정답 확인 질환 사진의 독립 평가는 남아 있다. |
| 3. Domain Gap 분석 | 픽셀·ROI·특징 분포 조사 완료. 사람·부위·질환·기기 효과를 완전히 분리하지 못했다. |
| 4. Partial Fine-tuning | 공개 데이터와 촬영 환경 적응 실험 완료. |
| 5. 입력 해상도 | 기존 비교·선정 완료. 현재 패키지 입력 크기를 유지한다. |
| 6. 증강·Loss·Backbone | 기존 연구와 측정 기반 변환·MMD/CORAL 결합 실험 완료. |
| 7. 최종 모델 선정 | 공개 데이터 후보와 장비 적응 후보를 구분해 보존. 공식 색인 자동 교체 없음. |
| 8. 논문 기반 강화 | 기록된 공개 데이터 비교 완료. |
| 9. Hair 양호 클래스 | 6클래스 공개 데이터 실험 완료. 원천 라벨·사람 단위 검증은 별도 후속이다. |
| 10. Router·시스템 통합 | 패키지 계약 준비와 실제 통합을 구분. UI·키오스크·장비 연결은 별도 범위 결정 후 진행한다. |
| 11. 구조 비교 | 별도 계획. 완료한 적응 연구에 포함하지 않는다. |
| 12. 실행 비용 | Colab 측정 완료. 실제 배포 기기의 속도·메모리·GPU 정보 등은 별도 측정이 필요하다. |
| 13. LLM 결과 설명 | 사용자 결정에 따라 카메라 적응 이후 작업으로 보류. |
| 14. VLM 독립 분류 | 사용자 결정에 따라 카메라 적응 이후 작업으로 보류. |

## 다음 작업 순서

1. 완료 결과와 수치 자료를 보고서·발표에 반영하고 현재 변경을 Git에 기록한다.
2. 실제 사용할 입력 장비·촬영 부위·모델 패키지와 UI 연결 범위를 확정한다.
3. 촬영 품질·범위 밖 입력·오류 처리를 검증하고 실제 배포 기기에서 실행 비용을 측정한다.
4. 정답 확인 실제 질환 자료를 확보하면 사람·기기·세션을 분리한 독립 평가를 한다.
5. LLM 설명과 VLM 실험은 전문 분류기의 역할·평가와 구분하여 착수한다.

로봇 제어·클러스터 구성은 공통 통합 범위를 먼저 확인한다.
새 실험은 Validation으로 설정을 고정하고 이미 본 Test를 반복해 강도를 고르지 않는다.
