## 현재 완료한 범위

기존 공개 데이터 분류 모델의 실험·선정과 실제 촬영 환경 적응 **1~4차 학습**, 기존 데이터 **Source Test 비교**를 완료했다. 실제 장비 질환 정답이 있는 독립 평가, 배포 장비 성능 측정과 전체 시스템 통합은 별도 과제다. 재설정 4차는 사용자가 실행하지 않기로 결정했고 미실행 보관한다. LLM·VLM은 촬영 적응 이후 작업으로 남겨 뒀다.

## 기본 모델과 1~4차의 관계

기본은 어댑테이션 전 저장 모델이다. 1차에서 각 분야의 초기 기본 모델·기존 선정 모델을 비교한 뒤 후속 출발점을 **피부 초기 B0·224, 얼굴 선정 PMG·B0·256, 두피 선정 B1·384 5클래스**로 고정했다.

| 단계 | 실제로 적용한 변화 | 완료한 학습 수 |
| --- | --- | ---: |
| 1차 | 피부 밝기·대비, 얼굴 밝기·대비·좌우 조명, 두피 밝기 | 6 · 3분야×초기/선정 |
| 2차 | 기존 조명에 측정한 색·미세 대비·약한 흐림 추가 | 3 |
| 3차 | 2차와 같은 사진 변환에 MMD·CORAL 특징 정렬 손실을 함께 추가 | 3 |
| 4차 | 촬영 자료를 다시 대조해 조명과 색·미세 대비·흐림 포함 여부를 재설계 | 3 |
| 합계 | 실제 완료한 적응 실험 | 15 |

2·3·4차는 앞 단계의 학습 완료 모델에 연속해서 더 학습한 것이 아니라, 1차에서 고른 **학습 전 저장 상태에서 각각 독립적으로 시작**했다. 각 실험은 5 epoch, seed 42, Adam 학습률 0.00001, 같은 분할·클래스 순서·입력 정책을 유지했다. Train 사진에는 50% 확률로 해당 변환을 적용했고 질환 라벨을 유지했다. 3차는 라벨 없는 실제 사진을 일부 배치의 특징 정렬에 사용했다.

1·2·4차는 측정 Target에 근거한 증강을 이용한 추가 학습이며, 3차가 MMD·CORAL을 손실로 사용한 비라벨 특징 정렬 실험이다. 특징 거리가 낮아진 것과 분류 정확도가 높아진 것을 구분한다. 색·미세 대비·흐림은 묶음으로 실험했고 MMD·CORAL도 함께 적용했으므로 개별 요소 하나의 기여는 분리하지 않았다.

별도 준비한 새 출발 모델 학습안·9개 통합 실행안·추가 확대 후보는 완료한 15개 실험에 포함하지 않는다. 9개 통합 실행은 두피 일부 회차를 확인한 뒤 중단했고 재설정 4차는 미실행 보관했다.

## 남은 일

1. 연구용 전달 패키징은 완료했다. 보고서 작성 시 패키지의 원본 학습·평가 기록과 위 과정 정리를 사용한다. 공통 추론 연결은 필요할 때 별도로 범위를 정한다.
2. 실제 장비 성능을 검증하려면 설정을 고정한 뒤 별도 인물·촬영 세션에서 정답이 확인된 질환 사진을 확보해야 한다. 현재 4명 자료로 실제 장비 질환 Accuracy를 계산하지 않는다.
3. 실제 배포 장비에서 추론 시간·자원 사용과 촬영 장비별 모델 선택·오류 처리를 확인한다. Colab 측정과 구분한다.
4. 이후 LLM·VLM 및 팀원 시스템의 통합 범위를 확정한다. 로봇 제어·클러스터 구성은 별도로 범위를 확인한다.

공개 데이터 연구에서 남은 원천 라벨·사람 단위 검증 등은 [로드맵](ROADMAP.md)의 별도 과제로 유지한다. 이미 확인한 Test를 반복해서 보며 변환이나 모델을 다시 맞추는 작업은 다음 단계로 삼지 않는다.
